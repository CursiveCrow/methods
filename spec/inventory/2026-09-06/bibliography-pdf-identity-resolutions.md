## Method and limits

Read actual opening title/author/version context for all 125unique candidate PDFs through the current first-four-page holdings extraction; inspected full relevant footer/copyright context where it changed a disposition. The exact candidates and their match contexts were also read. Score was never used as acceptance.

Retained each key/PDF pair as a separate disposition. One PDF can be the exact requested work for one key and a false positive or different version for another.

Freshly hashed all 125candidate representatives; every hash matched. The multiple physical copies in the input remain listed, but this task's fresh candidate-hash check is representative-based. The image-only packet separately checked its33 physical copies.

Used exact-hash image-only identities and the selected source-holdings packet, plus bounded current acquisition/source-note passages, as evidence for edition, extent and documented reading scope.

Added six specific holdings documented by those notes as supplements, not as extra scored candidates. This recovers exact report/book holdings that an opening-text title matcher missed and records McMillan's related thesis version.

A full local work/version identity is not full mathematical reading or source-fidelity acceptance. Existing reading/review records are reported at their stated source/snapshot scope; this inventory did not rerun or re-admit those reviews.

No source downloads, manuscript/bibliography/register edits, tests, builds or PDF page renders were performed. Original PDF rasters were inspected in memory for the separately requested report endpoint addendum; the input bibliographic and holdings inventories were unchanged.

The JSON preserves the exact current bibliography fields, entry line ranges and entry hashes; original candidate paths/copies; observed document identities; fresh file hashes; per-candidate reasons; and the specific reading/review records used. The full metadata snapshots are identified by SHA-256. No candidate is accepted because it scored highly.
