## New current host finding: CSL interval closure

At [lines 1365–1369](C:/Dev/the-methods-of-reason/handbook/parts/p09/logic-in-computer-science.tex:1365), the current definition says that, because residence times are continuous, replacing a nonempty interval I by its closure does not change path probability. This assertion is false for the displayed until semantics at [1377–1380](C:/Dev/the-methods-of-reason/handbook/parts/p09/logic-in-computer-science.tex:1377).

Take one absorbing state s, with R(s,s)=0 and p true. Its trajectory remains at s. Using the allowed formula neg top as false:

- `(neg top) U^(0,1] p` has probability **0**. Any witness t>0 requires neg top at u=0, which is false.
- `(neg top) U^[0,1] p` has probability **1**. The witness t=0 is allowed and its earlier-time guard is empty.

This uses the actual absorbing and final-trajectory clauses at lines 1331–1345. The zero endpoint is a semantic case, not a probability-zero transition-time event. The blanket closure assertion needs removal or a correctly scoped replacement preserving endpoint flags and the t=0 case.

The JSON records **NEW-P9-CSL-INTERVAL-CLOSURE** as a confirmed remaining host finding. It does not attribute this error to the cited Baier–Haverkort–Hermanns–Katoen paper, which was not re-read in this task. No book correction was made.
