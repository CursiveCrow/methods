The measure is not simply “number of variables in E.” A retained isolated
left variable stays in E after it is solved. The first coordinate therefore
counts Var(E) minus the permanent isolated left variables. Decompose removes
exactly two outer nodes when that first coordinate is unchanged; Delete
removes positive size; Orient decreases bad orientation when neither earlier
coordinate decreases. Every other-equation Eliminate makes its formerly
nonisolated variable isolated while preserving all old isolated bindings.
For the removing accumulator, the simpler residual-variable count decreases
because the selected binding really is removed. These are different measures
for different literal procedures, not a relabeled generic theorem.

## Worked failures of plausible substitutes and repair package

### Composition and triangular extraction

On x=y,y=a, the accumulator's first binding is x to y and its next is
y to a. **theta delta** yields x to a,y to a. Reversing the order yields
x to y,y to a, whose simultaneous images of the original x=y are y and a.
That map is not a unifier and is not idempotent. The same triangular map
would be a wrong premature extraction of the sheet's nonterminal state.

Crucially, Eliminate on x=y is **disabled** on the sheet in this example:
x occurs nowhere else. Its only pertinent elimination is on y=a, which
updates the already isolated retained x-binding and yields x=a,y=a.
The source's first removing step therefore has no sheet counterpart.
This distinction is explicit in the new worked case.

### Occurs, alias cycles, scanning and irrelevant variables

- x=y,y=f(x) fails under either elimination order by a proper self-occurrence.
- x=y,y=x succeeds: elimination turns the other equation into y=y, then
  Delete leaves the solved alias x=y. A bare variable cycle is not a finite
  function-tree occurs obstruction.
- x=a,f(y)=f(a) requires scanning past the disabled isolated first binding;
  Decompose on the second equation supplies the actual solved result.
- An unused w stays fixed in the returned map, while a further solution
  may send w to f(a); the global factorization still holds.
- Empty constraints and matching nullary atoms return identity. Predicate
  symbol mismatch fails before term transitions. Identity atoms are paired
  in written argument order, not modulo semantic symmetry.

### MGU uniqueness is not witness uniqueness

For x=a, mu={x to a} has both factor witnesses eta1=id and eta2={x to a}
for the same final map mu. They differ at an original input variable and
one is not a variable renaming. The current P12 sentence about the
factorization being unique should be replaced by the explicit comparison
of two MGUs, with the actual instance-preorder scope retained.
