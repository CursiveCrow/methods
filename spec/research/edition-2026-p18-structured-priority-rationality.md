direct strict elitist/democratic comparison. It assumes neither disjoint
trees nor local return (R).

  combined support. A direct support-union proof establishes this condition
  for jointly defended arguments, without assuming (R). Together these
  establish all the claimed extension-rationality results.

  arbitrary pairs. Its failure cannot occur for jointly defended pairs.
- All corrected priorities satisfy reasonableness for actual strict tree
  continuations, including repeated indexed families. Weakest link also
  satisfies the source's broader profile-continuation conditions.
- A two-rule countermodel disproves last-link singleton invariance for
  the literal profile-continuation relation.

The complete construction:

1. Finite strict partial orders supply the minimal elitist or maximal
   democratic resource witnesses needed at identified target subtrees.
2. Transposition reverses an actual path, retaining the opposing tree
   and all inserted off-path subtrees.
3. Full consequence contraposition supplies a derivation from the two
   opposing root conclusions; whole copies of those argument trees
   are grafted into it. No resource-padding rule is assumed.
4. Return is proved separately for last-link defeasible/strict attackers
   and weakest-link defeasible-root/ordinary targets, for both set lifts.
5. Every defeater of a graft hits an unchanged original subargument.
   The comparison remains at that target.
6. In the restricted support lemma, a minimal ordinary premise in a
   minimal c-inconsistent support set has an admitted strict
   counterargument that is not weaker under any of the four priorities.
7. Joint support and return establish attack compatibility of defended
   arguments, semantic equivalence, and the full consistency/closure result.

Repeated indexed families are treated by a finite-index strict-descent
argument. Equal arguments at different indices cannot create a strict
comparison between equal resource sets. No proof removes every occurrence
of a subtree merely because one occurrence is challenged.

## Countermodels and worked comparisons

The profile countermodel has axiom q and rules d1: q implies r,
d2: r implies q, both defeasible, with d1 below d2. A tree ending in
d2 and its continuation by another d1 application have identical premise
and used-rule sets but different last rules. Thus the profile condition
mistakenly admits another defeasible step as a strict continuation;
last-link singleton invariance fails. The actual strict-tree condition
and its theorem remain valid.

The global-return countermodel uses all finite classically valid strict
inferences, axiom not p, ordinary premises a,p with a below p, and
one defeasible rule a implies r. A tree strictly deriving not p from
r and the axiom not p unsuccessfully undermines [p].
Each support is consistent but their union is not. Every admitted
argument has a valuation with a,r and the rule name true, so none can
attack that tree's fallible components. Global return fails for all four
priorities. An unattacked axiom argument defeats [p], so the failed pair
cannot be jointly defended.

The five-argument worked system has a below b and d1 below d3 below d2.
Both last-link choices select the argument ending in d2; weakest-link
elitism selects its opponent ending in d3; weakest-link democracy makes
both attacks succeed and gives two preferred/stable extensions.
All trees, edges, comparisons, and complete extensions are calculated.
