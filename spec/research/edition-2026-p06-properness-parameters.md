## Exact model test and cardinal hypotheses

The actual reader poset is the tuple Pbold=(P,leq,1), with smaller
conditions stronger. Its standing bound is
kappa=max(aleph1,|tc({Pbold})|). Every regular chi>2^kappa is a
book-admissible height. The model is a countable N elementary in the
pure membership structure (Hchi,in), required to contain Pbold but no
auxiliary datum. For each p in P intersect N, a possibly non-N q<=p
must make every dense D in N satisfy that D intersect N is predense
below q. The same q precedes all dense-set tests for this fixed p.

The completed equivalence has four precisely quantified versions:

1. This bare-poset test holds for every admissible height and model.
2. Good master traces contain a club in [X]^omega, where
   X=omega union P union Pow(P).
3. At one regular Theta>2^kappa, a club of elementary submodels of
   HTheta containing Pbold has master production below every p in it.
4. At one such Theta, for one fixed A in HTheta, every countable
   elementary model containing Pbold and A has that master production.

In version four A can be the entire iteration datum. It need not belong
to smaller admissible Hchi. No GCH, ccc, countable closure, inaccessible
cardinal, supplied generic or transitive-ground premise is used in the
parameter bridge. It is a ground ZFC argument. The original source's
stationary-preservation characterization is not used as an imported
converse theorem here.

## Construction resolving the dependency

The small universe contains every actual dense subset, not a selected
enumeration. Every member of X has hereditary size at most kappa;
X and its complete set of countable subsets have hereditary size at
most 2^kappa. This uses (2^kappa)^aleph0=2^kappa in ZFC. Every individual
finite-input/countable-output code and every individual club on [X]^omega
has the same bound. Their full collections need not belong to Hchi.
All actual countable traces, enumerations and countable club chains do
belong there, so the countability, clubhood and good-trace tests are
absolute with the exact full underlying objects.

For an infinite Z and any club C on [Z]^omega, recursively choose
c_a in C containing each finite a and all c_b for proper subsets b of
a. The code a maps to c_a has a club of closure points contained in C:
enumerate a countable closed Y, take its increasing finite initial
segments, and union their increasing c_a values to obtain exactly Y.
This proves club coding rather than naming it as a missing lemma.

Apply that construction to a large good-model club on HTheta, with
code f. Let h(S) be its least closed hull. For finite a subset X put
g(a)=h(a) intersect X. The proof establishes finite character
h(Y)=union of h(a) for finite a subset Y. If Y is g-closed,
h(Y) intersect X=Y. Moreover h(Y) belongs to the original large-model
club, hence its master production proves Good_P(Y). This constructs a
club contained in the trace image; it does not falsely claim that every
naive projected image is closed.

At an arbitrary smaller admissible Hchi, a first-order assertion with
Pbold as its only parameter says that a code g has only good closure
points. The actual projected code witnesses this existential assertion
in Hchi. By elementarity the tested bare model selects its own g_N in
N. For finite a subset N intersect X, a and g_N(a) belong to N. The
output is countable, so all its elements belong to N. Thus N intersect
X is g_N-closed and is good. This gives exactly the book's master test.
No master from a larger model is inherited downward.

The converse club-good-model implication is supplied by the explicit
Skolem-hull/Tarski--Vaught club of elementary models containing Pbold,A.
The proof therefore closes the four-way equivalence, including the
change of height and removal of a parameter too large for the small height.

An atomic proper poset provides the worked failure of naive inheritance.
Take uncountably many atoms and a top. An atom outside a countable N,
but inside a larger countable elementary M, is an M-master. The dense
set of all atoms belongs to N, but its N-part is incompatible with the
chosen atom. Hence that atom is not an N-master. Another atom in N is
an N-master below the top, so the example does not contradict properness.
