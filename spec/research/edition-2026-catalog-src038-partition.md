This producer is materially different from SRC-037's:

- Several files are emitted beneath a single shared heading. A parent is therefore not generally an artifact identity.
- JSON traversal emits scalar leaves and empty containers, rather than every object/array node. It then emits the complete serialized physical-text presentation separately.
- HTML uses Python `HTMLParser` with character-reference conversion disabled. It emits exact start-tag strings, attribute names/values, end tags, data fragments, entity/character references and comments; it also traverses `__NEXT_DATA__` JSON and emits serialized HTML text.
- XML traversal emits tags, attributes and text/tail fields, followed by serialized text. JSON Lines has its own record/address construction.
- Decoding tries UTF-8, then Windows-1252, then reversible Latin-1 byte mapping. Its physical splitting uses `str.splitlines(keepends=True)` and records the producer's literal CRLF/LF/CR/none classification. SRC-037's different line grammar was not substituted.
- The producer's historical sensitive-shape predicate replaces some values with a length/hash descriptor. Those original masked records remain masked. The exact source artifact is independently identified by its retained file/hash; the catalog row is not falsely described as a literal copy of a masked value.
- Binary payloads receive file identity descriptors; the source does not transcribe all binary content into topic rows.
- The Prospectus renderer has eighteen page headings. Each page receives a render descriptor, a fixed historical visual-observation assertion, and four OCR formats. The final page heading also contains the recognition log and all contact-sheet descriptors/observations, because no new heading is inserted before them.
- A final flat inventory lists every retained artifact. Its 489 inventory records do not count 489 intellectual presentations.
