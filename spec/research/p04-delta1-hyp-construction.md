## Decisive construction being written

1. Give the exact simultaneous O rules and the actual oracle jump/join.
2. Construct the total syntactic notation addition Add(a,b), prove validity,
   ordinal addition and preservation of the notation predecessor relation.
3. Construct a uniform reduction H_b <=T H_Add(a,b), including the limit
   oracle-column program. No arbitrary comparison of equal ordinal notations
   or Spector uniqueness theorem is imported.
4. For a recursive well-founded child relation assign each node the computable
   code h(s)=succ^2(lim e_s), where e_s enumerates increasing cumulative sums
   Add(succ(a_n), h(child_n)), with dummy 1 for an absent child. Ordinary program
   self-reference supplies the code generator; well-founded induction proves
   validity. A code compiler does not evaluate all child subtrees.
5. Evaluate the alternating pair-tree equation by two actual jumps of the
   limit join. Give the two halting-program indices, the child oracle reduction
   and the uniform self-referential evaluation program. Prove termination and
   correctness by well-founded induction, not by assuming recursion closure.
6. A complementary pair of Pi-one-one recursive trees yields a single recursive
   well-founded product forest. The alternating equation separates the two
   cases. A common root gives one fixed valid jump oracle deciding every input.
7. Conversely, unfold any fixed valid notation into a recursive well-founded
   computation tree. The unique hierarchy is specified by an arithmetical
   set equation. Existentially quantify its code for either bit; uniqueness and
   existence give both Sigma-one-one definitions. Repeat for total Turing
   reductions.

All selections in the tree-normal-form and path arguments are least-natural
selections. Set recursion is ordinary classical ZF set recursion. No arbitrary
countable choice, desired equality, effective rank-bound theorem, admissibility
claim, or truth fixed-point bound is an assumption.
