# P4: source-scoped CPL notation and lookup declarations

Date: 7 September 2026. These are canonical-data and reader-policy corrections
following the independent D-P2-010 publication findings. They are not formal
supersession/admission or acceptance of generated views.

The new CPL body and annex already agree with the exact inherited grammar and
valuation clauses. The defects were in the normative notation apparatus:
global exclusivity for elementary-equivalence notation, numerical truth values
in the source CPL row, and missing occurrence-operation entries. The body and
proofs were not rewritten into another convention.

## Changes

The P1 symbol-registry introduction now describes editorial defaults with
explicit source-local typing, rather than imposing incompatible universal
reservations. It distinguishes formula operands from structure operands for
equiv. It states the source truth-value set {bold F, bold T} and the explicit
F-to-0/T-to-1 coding used by numerical Boolean tables, without equating the
sets literally.

The canonical CSV now records the source CPL truth-value set/values and semantic
formula-equivalence role. Existing editorial formula-equivalence and elementary
structure-equivalence rows remain with accurate qualifications. Domain/bar
wording is likewise qualified for typed source presentations. The complemented
valuation row distinguishes numerical subtraction from swapping source labels.

The newly defined position-set, subformula-at-position, selected-replacement
and empty-root-address roles now have P2.1 entries and exact definition links.
The existing uniform-substitution map and instance rows were retained. All
entries were derived from actual active definitions; no new mathematical
notation or calculus was invented by the registry.
