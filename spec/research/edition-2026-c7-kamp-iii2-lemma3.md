The argument defines the replacement truth set A in the original structure,
even if P_i occurs inside the replacement. A is independent of the ambient
assignment because the replacement has exactly one free variable. This is
why the quantifier induction can use a single modified interpretation while
changing the quantified variable's assignment. No fixed-point meaning or
unmentioned free parameter is introduced.

The temporal proof likewise interprets its replacement in the original
structure. It checks the strict past witness and every past interval point
separately from the strict future witness and every future interval point.
The first-order D truth proof explicitly handles all primitive temporal
constructors. Hence the D/substitution compatibility equation is a proved
semantic equivalence for arbitrary binary structures on a nonempty domain;
the expressibility application then keeps Lin as the stated structure class.

The source-selected bound names need not be literally the names selected by
the D recursion. The text proves truth compatibility and the relevant
alphabetic-variant relation without equating those strings. Ordinary
variable substitution was stated for arbitrary formulas before its
structural induction so that the quantifier matrices, which can have more
free variables, are within the induction claim.

The input to the finite construction is a finite E-construction history.
It does not claim to decide membership of an arbitrary bare first-order
formula. The output is a finite TL1 formula. At every node its proposition
letters exactly correspond to the unary predicate letters in the resulting
first-order formula. The absent-target case is handled separately so an
unused replacement introduces no new letter. An inserted target predicate
is retained when it already occurs inside the replacement, as required by
single-pass substitution.

The example substitutes the source witness-point past limit of C into the
C endpoint of a basic future pattern. The explicit first-order formula
tests that limit at the selected future endpoint. Its temporal expression
is `A-hat AND U(P'(C-hat), B-hat)`. The internal C occurrence is retained.
Both the no-future-witness case and the empty intervening interval case are
checked. The example is an additional handbook calculation, not attributed
as Kamp's printed example.
