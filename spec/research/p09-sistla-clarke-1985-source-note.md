## Languages, structures, and exact temporal semantics

Let \(\mathcal P\) be the finite set of atomic propositions used by the
formulae under discussion. For distinct operators
\(O_1,\ldots,O_k\in\{X,F,G,U,S\}\), the source writes
\(L(O_1,\ldots,O_k)\) for the fragment restricted to those temporal
operators ([journal pp. 734--735](https://www.cs.cmu.edu/~emc/papers/Papers%20In%20Refereed%20Journals/TheComplexityOfPropositionalLinearTemporalLogics.pdf#page=2)).

The journal's displayed general formation clauses use atoms, Boolean
negation and conjunction, unary next \(X\), binary until \(U\), and binary
since \(S\). It defines

\[
\begin{aligned}
 f_1\lor f_2 &\equiv \neg(\neg f_1\land\neg f_2),\\
 f_1\supset f_2 &\equiv \neg f_1\lor f_2,\\
 Ff &\equiv \mathit{True}\ U\ f,\\
 Gf &\equiv \neg F\neg f.
\end{aligned}
\]

Thus \(F\) and \(G\) are displayed as abbreviations in the journal's grammar.
This differs from the conference syntax display, which lists \(Ff\) and
\(Gf\) among the inductive formula forms before also recording their
equivalences.

The source separately defines \(\widetilde L(F,X)\) to use the Boolean
connectives \(\land,\lor\), temporal operators \(F,X\), and negation only
directly on atomic propositions ([journal p. 735](https://www.cs.cmu.edu/~emc/papers/Papers%20In%20Refereed%20Journals/TheComplexityOfPropositionalLinearTemporalLogics.pdf#page=3)).
This is a syntactically restricted formula language. It is not full
\(L(F,X)\), because it does not permit arbitrary alternation of \(\neg\) and
\(F\), and hence does not recover arbitrary \(G\)-nesting.

A temporal structure is

\[
 S=(s,\xi),\qquad s=(s_0,s_1,\ldots),\qquad
 \xi:s\longrightarrow 2^{\mathcal P},
\]

where the state tokens in \(s\) are all distinct. Distinct state tokens may
carry the same proposition set. An interpretation is a pair \((S,\delta)\)
with \(\delta\) one of the state tokens. The point clauses are

\[
\begin{aligned}
 S,s_i\models P
 &\Longleftrightarrow P\in\xi(s_i),\\
 S,s_i\models f_1\land f_2
 &\Longleftrightarrow S,s_i\models f_1\text{ and }S,s_i\models f_2,\\
 S,s_i\models\neg f
 &\Longleftrightarrow S,s_i\not\models f,\\
 S,s_i\models Xf
 &\Longleftrightarrow S,s_{i+1}\models f,\\
 S,s_i\models f_1 U f_2
 &\Longleftrightarrow
 \exists k\ge i\bigl(S,s_k\models f_2\land
 \forall j\,(i\le j<k\Rightarrow S,s_j\models f_1)\bigr),\\
 S,s_i\models f_1 S f_2
 &\Longleftrightarrow
 \exists k\le i\bigl(S,s_k\models f_2\land
 \forall j\,(k<j\le i\Rightarrow S,s_j\models f_1)\bigr).
\end{aligned}
\]

Until is strong and permits its right operand at the current point. Since
permits its right operand at the current point as the case \(k=i\); when its
witness is earlier, its left operand holds through the current point.

The source defines \(\operatorname{length}(f)\) as the number of symbols in
\(f\). Its journal closure \(SF(f)\) starts with the ordinary syntactic
subformulae of \(f\) and adjoins each one's single-negation mate: for
\(h\) not headed by \(\neg\), adjoin \(\neg h\); for \(h=\neg h_0\), adjoin
\(h_0\). Thus double negations are eliminated, and

\[
 \operatorname{card}(SF(f))\le 2\operatorname{length}(f).
\]

This is an eliminable metalinguistic formula closure, not a temporal operator
or a set of formulae assumed true at a state. The single-negation mates
distinguish it from the ordinary subformula set and are required by the
certificate labels and later type and periodicity arguments. The 1982 source
defined `SF` only as the set of subformulae at this location; the explicit
negation closure and bound are journal additions.

## The two principal decision problems and the validity corollary

An \(R\)-structure is

\[
 T=(N,R,\eta),
\]

where \(N\) is finite, \(R\subseteq N\times N\) is total, and
\(\eta:N\to2^{\mathcal P}\). A path is an infinite sequence
\(p=(p_0,p_1,\ldots)\) satisfying \((p_i,p_{i+1})\in R\). The induced
temporal structure \(S_p\) repeats along fresh positions the labels
\(\eta(p_i)\).

The article studies two main input problems:

1. **Satisfiability:** does a supplied formula hold at some point of some
   temporal structure?
2. **Determination of truth in an \(R\)-structure:** given
   \(T=(N,R,\eta)\), \(\delta\in N\), and \(f\), is there a path \(p\)
   beginning at \(\delta\) such that \(S_p,s_0\models f\)?

The second problem is literally existential ([journal p. 735](https://www.cs.cmu.edu/~emc/papers/Papers%20In%20Refereed%20Journals/TheComplexityOfPropositionalLinearTemporalLogics.pdf#page=3)).
It must not be silently renamed universal model checking. The preceding
program discussion says a program satisfies a requirement when every path
satisfies it; an existential `R`-truth query therefore detects a violation by
being applied to the negation of a universal requirement.

Table I separately includes a validity column, but the journal article does
not print a formal validity clause. The 1982 conference predecessor does print
the universal all-structures/all-positions definition on p. 160. Relative to
the controlling journal's definition of an interpretation, the same standard
complement reading is truth at every point of every temporal structure. The
handbook may make that quantifier explicit only as a reconstruction relative
to the journal, not as text attributed to journal p. 735; the conference clause
is predecessor evidence. Validity is not one of the
two problems named in Theorems 3.5, 3.7, 4.1, or 5.4; Table I records its
corresponding complement classification ([journal p. 748](https://www.cs.cmu.edu/~emc/papers/Papers%20In%20Refereed%20Journals/TheComplexityOfPropositionalLinearTemporalLogics.pdf#page=16)).

## Section 3: the exact `L(F)` small-model and NP chain

For a structure \(S=(s,\xi)\), let `final(S)` be the unique maximal suffix in
which every valuation appearing there appears infinitely often. If
\(s=s'\cdot s''\) with \(s''=\operatorname{final}(S)\), define

\[
\begin{aligned}
 \operatorname{init}(S)&=s',\\
 \operatorname{final}(S)&=s'',\\
 \operatorname{range}(S)&=\{\xi(s_k):s_k\text{ occurs in }s''\},\\
 \operatorname{size}(S)&=
 \operatorname{length}(\operatorname{init}(S))+
 \operatorname{card}(\operatorname{range}(S)).
\end{aligned}
\]

This `size` is the source's finite description measure for an infinite
sequence. It is not the cardinality of a finite temporal model.

The exact dependency chain is:

1. **Lemma 3.1, p. 736.** Two states in `final(S)` with the same valuation
   satisfy exactly the same \(L(F)\) formulae. A structural-induction proof is
   printed.
2. **Lemma 3.2, p. 736.** For structures \(S=(s,\xi)\) and \(T=(t,\pi)\), let
   \(m=\operatorname{length}(\operatorname{init}(S))\). Its exact hypotheses
   and conclusion are
   \[
   \begin{gathered}
   m=\operatorname{length}(\operatorname{init}(T)),\qquad
   \xi(s_j)=\pi(t_j)\quad(0\le j<m),\\
   m=0\Longrightarrow\xi(s_0)=\pi(t_0),\qquad
   \operatorname{range}(S)=\operatorname{range}(T)
   \end{gathered}
   \quad\Longrightarrow\quad
   \forall f\in L(F)\quad
   \bigl(S,s_0\models f\Longleftrightarrow T,t_0\models f\bigr).
   \]
   The first-valuation clause supplies the zero-length boundary case; when
   \(m>0\), it is already included in the pointwise prefix equality. The source
   says the lemma can be proved by induction but does not print the cases.
3. The paper defines a subsequence and then an *acceptable subsequence*:
   whenever it retains one final-state token, it retains all final-state
   tokens having that valuation. Its measures for an acceptable subsequence
   \(t\) are relative to the ambient structure \(S\). Specifically,
   \(\operatorname{init}(t)\) is the longest prefix of \(t\) that is a
   subsequence of \(\operatorname{init}(S)\);
   \(\operatorname{final}(t)\) is the suffix beginning with the state
   immediately after \(\operatorname{init}(t)\); and
   \(\operatorname{range}(t)\) and \(\operatorname{size}(t)\) are defined as
   above, all relative to \(S\). To expose this hidden parameter, this note
   writes the eliminable metalinguistic variants

   \[
   \begin{aligned}
   \operatorname{init}_{S}(t)&=\text{that longest prefix},\\
   t&=\operatorname{init}_{S}(t)\cdot\operatorname{final}_{S}(t),\\
   \operatorname{range}_{S}(t)
     &=\{\xi(q):q\text{ occurs in }\operatorname{final}_{S}(t)\},\\
   \operatorname{size}_{S}(t)
     &=\operatorname{length}(\operatorname{init}_{S}(t))
       +\operatorname{card}(\operatorname{range}_{S}(t)).
   \end{aligned}
   \]

   These subscripts name no new source object or relation: they are necessary
   only to prevent ambiguity about the ambient sequence, differ from the
   source's un-subscripted notation only by exposing that parameter, and are
   used below to type the extraction bound. The same source paragraph says
   that if \(t_1,t_2\) are acceptable and \(v\) contains, in source order,
   exactly the state tokens occurring in either, then \(v\) is acceptable. It
   literally prints

   \[
   \operatorname{size}(v)
   <
   \operatorname{size}(t_1)+\operatorname{size}(t_2).
   \]

   The strict form fails when both inputs are the null subsequence. The
   following conjunction induction instead uses the proof-supported
   subadditivity fact

   \[
   \operatorname{size}_{S}(v)
   \le
   \operatorname{size}_{S}(t_1)+\operatorname{size}_{S}(t_2).
   \]
4. Let \(\mu(f)\in\mathbb N\) count exactly the occurrences of the symbol
   \(F\) in \(f\). It is a metalinguistic formula measure, distinct from total
   formula length, and is required by the extraction bound. The source pushes
   negations to atoms using the \(F/G\) dualities.
5. **Lemma 3.3, pp. 736--737.** Let \(t\) be an acceptable subsequence of the
   sequence of \(S=(s,\xi)\), and let \(f\in L(F,G)\) be in negation-normal
   form and hold at every represented position of \(t\). The lemma extracts an
   acceptable subsequence \(u\) of \(s\) with the literal printed bound
   \(\operatorname{size}(u)<\mu(f)\), which is
   \(\operatorname{size}_{S}(u)<\mu(f)\) when the ambient parameter is
   exposed. Its preservation quantifier ranges over
   **every** sequence \(w\) with \(u\) a subsequence of \(w\) and \(w\) a
   subsequence of \(s\). If \(W=(w,\varphi)\) and \(\varphi\) restricts
   \(\xi\) to the states in \(w\), then
   \[
   w_r\text{ occurs in }t\quad\Longrightarrow\quad W,w_r\models f
   \qquad\text{for every represented position }w_r\text{ of }w.
   \]
   Thus the result is stable under every intermediate supersequence, at the
   surviving positions inherited from \(t\); it is not merely a model-thinning
   claim. The structural induction is printed.
6. **Theorem 3.4, p. 737.** If \(f\in L(F)\) is satisfiable, it has a
   structure \(S\) with
   \[
      \operatorname{size}(S)\le\operatorname{length}(f).
   \]
   The source explicitly labels the argument `PROOF SKETCH`.
7. **Theorem 3.5, pp. 737--739.** Both satisfiability and determination of
   truth in an \(R\)-structure are NP-complete for \(L(F)\).

### The printed inequality defect in Lemma 3.3

The displayed statement of Lemma 3.3 prints

\[
 \operatorname{size}(u)<\mu(f),
\]

where the source's context-dependent left side is
\(\operatorname{size}_{S}(u)\) in the explicit notation above.
The preparatory acceptable-union sentence has the parallel strict-sign defect
recorded above.
That strict inequality fails in the printed atomic basis, where
\(\mu(f)=0\), the chosen null sequence has size zero, and the proof requires
\(0\le0\). The following induction repeatedly derives
\(\operatorname{size}_{S}(u)\le\mu(f)\), and Theorem 3.4 invokes the lemma with
the non-strict bound. The evidence therefore supports a local printed
strict/non-strict error. A faithful reconstruction must report the literal
`<` and then identify the proof-supported correction \(\le\); it must not
silently quote the corrected inequality as though that is what the lemma
prints ([journal pp. 736--737](https://www.cs.cmu.edu/~emc/papers/Papers%20In%20Refereed%20Journals/TheComplexityOfPropositionalLinearTemporalLogics.pdf#page=4)).

### NP hardness and membership

For existential \(R\)-truth, Theorem 3.5 reduces 3-SAT to a chain of diamonds,
one per Boolean variable. A path chooses the positive or negative literal;
the chosen literal's node is labelled by the clauses it satisfies. The target
formula is

\[
 FC_1\land FC_2\land\cdots\land FC_m.
\]

It has no nesting of temporal operators. This proves the source's introductory
claim that the \(R\)-truth problem is hard even for simple unnested
eventualities ([Figure 1 and proof, p. 738](https://www.cs.cmu.edu/~emc/papers/Papers%20In%20Refereed%20Journals/TheComplexityOfPropositionalLinearTemporalLogics.pdf#page=6)).

For membership, write \(q_0:=\delta\) for the supplied start node. This is the
source's eliminable metalinguistic name for that input, not a second graph
node; it is introduced to bind the prefix and acceptance clauses. The
procedure guesses
\[
 p'=(x_0,\ldots,x_r),\qquad x_0=q_0,\qquad
 \operatorname{length}(p')\le
 \operatorname{length}(f)\operatorname{card}(N),
\]
and a subset \(C\subseteq N\). It checks that \(p'\) is a path, that the graph
on \(C\) with edges \(R\cap(C\times C)\) is strongly connected, and that an
edge leads from \(x_r\) into \(C\).

The paper then assigns one label to every graph node occurring in the prefix
or in \(C\), while its eventuality clause refers to a particular occurrence of
that node. This is ill-defined when a node repeats. A concrete counterexample
is
\[
\begin{gathered}
 N=\{x,u,c\},\qquad R=\{(x,u),(x,c),(u,x),(c,c)\},\\
 \eta(u)=\{a\},\qquad \eta(x)=\{b\},\qquad \eta(c)=\varnothing .
\end{gathered}
\]
The path \(x,u,x,c,c,\ldots\) satisfies
\(Fa\land F(b\land\neg Fa)\): \(Fa\) holds at the first occurrence of \(x\)
and fails at the second. One node label cannot carry both truth values.

The handbook repair uses an occurrence-indexed set \(\mathcal L_i\) for each
prefix position \(0\le i\le r\) and a separate recurrent-node summary
\(\mathcal L_C(x)\) for each \(x\in C\). Atomic and Boolean clauses are
evaluated within the appropriate set, and the exact eventuality clauses are
\[
\begin{aligned}
 Fg\in\mathcal L_i
 &\Longleftrightarrow
   \exists j\,(i\le j\le r\land g\in\mathcal L_j)
   \lor\exists y\in C\,(g\in\mathcal L_C(y)),\\
 Fg\in\mathcal L_C(x)
 &\Longleftrightarrow
   \exists y\in C\,(g\in\mathcal L_C(y)).
\end{aligned}
\]
The non-strict prefix bound is forced by the inclusive semantics of \(F\).
A strict reading would reject the total graph
\[
N=\{q_0,d\},\qquad R=\{(q_0,d),(d,d)\},
\qquad \eta(q_0)=\{A\},\quad\eta(d)=\varnothing,
\]
for the true formula \(A\land FA\).

The certificate accepts exactly when \(f\in\mathcal L_0\). With the cycle
correction below, a suffix can visit every node of \(C\) infinitely often, and
a structural induction justifies both eventuality clauses. There are
\(r+1+\operatorname{card}(C)\) finite truth sets, each contained in \(SF(f)\),
so the occurrence-sensitive repair preserves the polynomial certificate bound.
These sets are metalinguistic certificate data, not the semantic source truth
sets introduced in Section 4.

The paper's literal graph check has a correctness gap under the standard
reflexive convention for strong connectivity: a loopless singleton is
strongly connected, but cannot support an infinite suffix. A concrete
counterexample is

\[
N=\{q_0,c,d\},\qquad
R=\{(q_0,c),(c,d),(d,d)\},
\]

with \(P\) true at \(q_0,c\) and false at \(d\). The only infinite path
falsifies \(GP=\neg F\neg P\), yet \(p'=(q_0)\), \(C=\{c\}\) passes the
printed connectivity and entry-edge checks and the printed labels accept.
The source does not state a positive-length reachability convention that would
exclude the guess. The handbook therefore adds, as its own correction rather
than a source attribution, the requirement that \(R\cap(C\times C)\) contain
a directed cycle. This is a self-loop requirement for singleton \(C\) and is
automatic for larger finite strongly connected \(C\). With that addition the
claimed recurrent infinite suffix exists. The satisfiability procedure guesses
`init(S)` and `range(S)` within Theorem 3.4's linear bound. Boolean
satisfiability supplies the other hardness direction
([journal pp. 738--739](https://www.cs.cmu.edu/~emc/papers/Papers%20In%20Refereed%20Journals/TheComplexityOfPropositionalLinearTemporalLogics.pdf#page=6)).

## The journal proof for `\widetilde L(F,X)`

**Lemma 3.6**, p. 739, states: if
\(f\in\widetilde L(F,X)\), \(S=(s,\xi)\), and \(S,s_i\models f\), then there
is a finite subsequence \(u\) of \(s\) which contains \(s_i\) and has
\(\operatorname{length}(u)\le\operatorname{length}(f)\). For every sequence
\(v\) with \(u\) a subsequence of \(v\) and \(v\) a subsequence of \(s\), if
\(V=(v,\varphi)\) restricts \(\xi\) to the states in \(v\), then
\(V,s_i\models f\). The every-intermediate-supersequence quantifier is
load-bearing in the induction; the proof prints the \(X\) case and refers to
the preceding arguments for the Boolean and \(F\) cases.

**Theorem 3.7**, p. 739, makes satisfiability and existential \(R\)-truth
NP-complete for \(\widetilde L(F,X)\). Its upper bounds explicitly invoke
Lemma 3.6 and adapt Theorem 3.5. Its lower bounds reuse the unnested formulas
already used for \(L(F)\) and ordinary 3-SAT.

The conference conclusion and its table named this restricted fragment and
asserted the NP classification, but the conference body had no Lemma 3.6 or
Theorem 3.7. The journal supplies the missing numbered small-model lemma and
proof rather than relying on the conference conclusion's informal claim that
the absence of \(G\) suffices.

## Section 4: exact PSPACE theorem and proof chain

**Theorem 4.1**, stated on p. 739 and proved on pp. 744--745, says that both
satisfiability and determination of truth in an \(R\)-structure are
PSPACE-complete for

\[
 L(F,X),\qquad L(U),\qquad L(U,S,X).
\]

Table I also includes \(L(U,X)\). It contains the PSPACE-hard fragment
\(L(U)\) and is contained in the journal's \(L(U,S,X)\) upper-bound language,
so the displayed table's PSPACE-completeness follows. The paper does not give
\(L(U,X)\) a separate numbered theorem; the conclusion also cites a later
journal version of the deterministic-PDL result for a different PSPACE upper
bound ([journal p. 748](https://www.cs.cmu.edu/~emc/papers/Papers%20In%20Refereed%20Journals/TheComplexityOfPropositionalLinearTemporalLogics.pdf#page=16)).

The Section 4 chain is:

1. **Lemma 4.2, p. 740.** If \(T\) is obtained from \(S\) by duplicating one
   state once, every \(L(U)\) formula retains its truth at all old states, and
   the two duplicate positions agree. The source says the proof is an easy
   induction and expressly notes that the lemma fails for \(L(U,X)\).
2. **Lemma 4.3, p. 740.** Determination of truth in an \(R\)-structure
   polynomial-time reduces to satisfiability for \(L(F,X)\), \(L(U)\), and
   \(L(U,S,X)\). Let \(T=(N,R,\eta)\), let \(f\in L(U,S,X)\), let
   \(\mathcal P_2\) be the atoms in \(f\), and introduce the disjoint atoms
   \(\mathcal P_1=\{P_x:x\in N\}\). For each \(x\in N\), the paper defines
   \[
   \begin{aligned}
   g_1^x&=\bigwedge\{Q:Q\in\eta(x)\},&
   g_2^x&=\bigvee\{Q:Q\in\mathcal P_2\setminus\eta(x)\},\\
   g_3^x&=\bigvee\{P_y:(x,y)\in R\},&
   f_x&=P_x\to(g_1^x\land\neg g_2^x\land Xg_3^x),\\
   h_1&=\bigvee_{x\in N}P_x,&
   h_2&=\bigwedge_{x\in N}f_x.
   \end{aligned}
   \]
   Empty conjunction and disjunction have their standard values \(\top\) and
   \(\bot\). The source describes \(h_3\) as asserting that exactly one
   proposition in \(\mathcal P_1\) is true at every point and forms
   \[
   f'=G(h_1\land h_2\land h_3),\qquad
   f''=f'\land f\land P_q
   \]
   for the supplied start node \(q\). Thus \(f''\) is satisfiable iff some
   path from \(q\) satisfies \(f\). Under the source's description of \(h_3\),
   \(h_1\) repeats its at-least-one part; both are retained because the paper
   explicitly prints both. All \(g_i^x,f_x,h_i,f',f''\) are eliminable
   metalinguistic names for formulas used only in the reduction, not new
   temporal operators; the names distinguish label reproduction, the unique
   graph-state marker, and the successor constraint.
3. If \(f\in L(F,X)\), the construction stays in that language. For the
   pure-until version of Lemma 4.3, the paper forms the same outer constraint
   but replaces each next-successor condition \(Xg_3^x\) by
   \[
   \begin{cases}
      P_x U g_3^x, & (x,x)\notin R,\\
      G(P_x)\lor\bigl[P_x U(g_3^x\land\neg P_x)\bigr], & (x,x)\in R.
   \end{cases}
   \]
   In the first case, finite repetition of \(P_x\) before a legal successor is
   harmless exactly because Lemma 4.2 proves stuttering invariance for
   \(L(U)\). The second case also permits the self-loop behavior of remaining
   at \(x\) forever.
4. **Lemma 4.4, pp. 741--742.** Existential \(R\)-truth is PSPACE-hard already
   for \(L(F,X)\) and for \(L(U)\). Figure 2 encodes computations of a
   deterministic one-tape polynomial-space Turing machine. The journal assumes
   that after the machine enters \(V_A\) or \(V_R\), that state persists forever
   and the tape is no longer changed; this totalizes a halting computation into
   an infinite temporal history. Each of the \(S(n)\) diamonds represents one
   tape-cell position. A complete BI-to-EI subpath through the whole chain
   selects one symbol at every cell and represents one instantaneous
   description; repeated traversals represent a sequence of descriptions.
   Printed p. 741 says the \(L(F,X)\) construction uses \(2S(n)\) next
   operators to relate corresponding cells in successive descriptions. The
   conference predecessor instead prints \(S(n)\) on p. 164. The journal's
   pure-until marker construction continues on p. 742 and is explicitly
   introduced as a brief sketch, although representative formulae are
   displayed.
5. For each state \(s_i\), define its formula type
   \[
      [s_i]_{S,f}=\{g\in SF(f):S,s_i\models g\}.
   \]
   This is a set of source subformulae, not a newly postulated semantic object.
   Although \(\operatorname{card}(SF(f))\le2\operatorname{length}(f)\), p. 742
   states that the number of such realized source truth sets is at most
   \(2^{\operatorname{length}(f)}\), not
   \(2^{2\operatorname{length}(f)}\). Each truth set is determined by the truth
   values of the actual subformulae because adding each single-negation mate
   creates no independent choice. The proof of Theorem 4.7 later applies the
   same count to the actual subformulae of \(g\), using
   \(2^{\operatorname{length}(g)}\). Closure cardinality and realized-type
   count are distinct statements and must not be collapsed into an unprinted
   power-set bound.
6. **Lemma 4.5, p. 742.** If \(i<j\) and
   \([s_i]_{S,f}=[s_j]_{S,f}\), the exact deletion is
   \[
   s'=(s_0,\ldots,s_{i-1},s_j,s_{j+1},\ldots),
   \qquad S'=(s',\xi'),
   \]
   with \(\xi'\) the restriction of \(\xi\) to the retained state tokens.
   Thus \(s_i,\ldots,s_{j-1}\) are removed and \(s_j\) is retained. For every
   state token \(s_k\) present in both \(s\) and \(s'\),
   \[
   [s_k]_{S,f}=[s_k]_{S',f}.
   \]
   The proof is not printed; the paper says it can be proved by induction on
   formula length.
7. A `U`-formula is a subformula \(g_1 U g_2\). If it holds at \(s_i\), it is
   *fulfilled before* \(s_j\), for \(j\ge i\), when its right operand holds at
   some position \(l\) with \(i\le l\le j\). The source uses this exact
   obligation in the loop lemma.
   At the same location the source defines, for \(i\in\mathbb N\) and
   \(p\in\mathbb N_{>0}\),
   \[
   S=(s,\xi)\text{ is ultimately periodic with starting index }i
   \text{ and period }p
   \quad\Longleftrightarrow\quad
   \forall k\ge i\quad\xi(s_k)=\xi(s_{k+p}).
   \]
   This is equality of the structure's complete propositional valuations, not
   equality of the restricted source truth sets and not discharge of a pending
   obligation. The finite representation is the valuation prefix before \(i\)
   plus the nonempty length-\(p\) block repeated forever.
8. **Lemma 4.6, pp. 742--743.** Let \(p>0\), suppose
   \([s_i]_{S,f}=[s_{i+p}]_{S,f}\), and require every `U`-formula in
   \([s_i]_{S,f}\) to be fulfilled before \(s_{i+p}\). Let
   \(S'=(s',\xi')\) be ultimately periodic with starting index \(i\) and
   period \(p\), with
   \[
   \xi(s_k)=\xi'(s'_k)\qquad(k<i+p).
   \]
   Then for every \(g\in SF(f)\), the lemma proves both
   \[
   \begin{array}{ll}
   \text{(a)}&\forall k<i+p\quad
   S,s_k\models g\Longleftrightarrow S',s'_k\models g,\\
   \text{(b)}&\forall k\ge i\quad
   S',s'_k\models g\Longleftrightarrow S',s'_{k+p}\models g.
   \end{array}
   \]
   The paper prints the structural induction, with Boolean and \(X\) cases
   abbreviated and the nontrivial \(U\) and \(S\) cases treated. These two
   conclusions must not be compressed into valuation periodicity alone.
9. **Theorem 4.7, pp. 743--744.** The ultimately periodic model theorem gives
   the exact bounds and obligation condition below.
10. The proof of **Theorem 4.1**, pp. 744--745, searches such a witness by
    retaining only counters and successive subformula types. If \(A,B\subseteq
    SF(f)\) are the present and next guessed sets, the exact local checks are
    \[
    \begin{array}{rcl}
    Xf_1\in A&\Longleftrightarrow&f_1\in B,\\
    f_1 U f_2\in A&\Longleftrightarrow&
      f_2\in A\lor(f_1\in A\land f_1 U f_2\in B),\\
    f_1 S f_2\in B&\Longleftrightarrow&
      f_2\in B\lor(f_1\in B\land f_1 S f_2\in A),\\
    f_1\land f_2\in A&\Longleftrightarrow&f_1,f_2\in A,\\
    \neg f_1\in A&\Longleftrightarrow&f_1\notin A.
    \end{array}
    \]
    Here \(A,B\) are eliminable metalinguistic guesses, needed to distinguish
    the two sides of the directional checks; they are not assumed-realized
    semantic types. At the initial position the machine additionally checks
    \(f_1 S f_2\in A_0\) iff \(f_2\in A_0\). It saves the loop-entry set,
    uses it as the next set when closing the guessed period, and requires the
    right operand of every `U`-formula in that saved set to appear within the
    period. It stores only the present, next, and loop-entry sets plus two
    counters. The nondeterministic machine uses space linear in formula length;
    the paper invokes Savitch's theorem to obtain a deterministic
    polynomial-space procedure. Lemmas 4.3 and 4.4 transfer the lower and upper
    bounds between the two principal problems.

## Exact ultimately periodic witness theorem

Theorem 4.7 says that \(f\in L(U,S,X)\) is satisfiable iff it is satisfiable
in an ultimately periodic structure in the exact valuation sense above, with
starting index \(i\in\mathbb N\) and period \(p\in\mathbb N_{>0}\) satisfying

\[
 i\le 2^{1+\operatorname{length}(f)},
 \qquad
 p\le 4^{1+\operatorname{length}(f)},
\]

such that, for every \(k\ge i\),

\[
 [s_k]_{S,f}=[s_{k+p}]_{S,f},
\]

and every `U`-formula in \([s_k]_{S,f}\) is fulfilled before
\(s_{k+p}\) ([journal pp. 743--744](https://www.cs.cmu.edu/~emc/papers/Papers%20In%20Refereed%20Journals/TheComplexityOfPropositionalLinearTemporalLogics.pdf#page=11)).

Because a formula containing since may be satisfiable only away from the
initial point, the proof applies the construction to \(g=Ff\). It reduces a
model by Lemma 4.5 while preserving a selected until-fulfilment interval,
then uses Lemma 4.6 to close the loop. Before closure it obtains at most
\(2^{\operatorname{length}(g)}\) relevant positions before the selected
point and at most
\(\operatorname{length}(g)2^{\operatorname{length}(g)}\) within the selected
interval; the stated powers follow from
\(\operatorname{length}(g)\le1+\operatorname{length}(f)\).

An ultimately periodic witness is still an infinite temporal structure. The
source supplies a finite prefix-and-period representation for search; it does
not assert that all temporal models are finite.

## Section 5: corrected extended temporal logic

The source's `ETL` extends temporal formulae with operators supplied by a
regular right-linear grammar. Let a grammar have terminal symbols
\(a_1,\ldots,a_n\), nonterminals \(N_1,\ldots,N_m\), and productions of the
form \(N\to aM\) or \(N\to a\), where \(a\) is a terminal string. Each
\(N_j(f_1,\ldots,f_n)\) is a formula. The source assumes disjoint
nonterminal names across different grammars, so the displayed head determines
its grammar. The satisfaction clause asks for a finite or infinite terminal
string generated from \(N_j\) whose symbol at each represented future position
selects an argument formula true at that position ([journal p. 745](https://www.cs.cmu.edu/~emc/papers/Papers%20In%20Refereed%20Journals/TheComplexityOfPropositionalLinearTemporalLogics.pdf#page=13)).

The grammar display permits an empty terminal string syntactically, but the
later consistency rules always consume a terminal and print no empty-emission
case. The handbook therefore restricts this reconstruction to
\(a\in\{a_1,\ldots,a_n\}^{+}\). This is a handbook-supplied proof-domain
restriction, not an attribution to the article; the epsilon-admitting extension
is not established here. Under that restriction, a production emitting
\(r\ge1\) terminals is replaced by a chain of \(r\) one-terminal productions
with fresh nonterminals, preserving generated strings with only linear growth
in the encoded production length.

Later on p. 745 the article locally uses \(q\) for the same generic number of
terminal arguments. This note alpha-renames that local variable to \(n\)
throughout the Section 5 reconstruction. The renaming is eliminable and
metalinguistic, imposes no new arity restriction, avoids collision with graph
start-state letters, and is used in \(\Gamma\), Lemma 5.2, and Theorem 5.4.

The printed clause says “finite or infinite string” and then uses a universal
index written \(l\ge0\). Read literally, that unrestricted index is not typed
for a finite string. The later proof makes the intended two cases operative:
a finite generated word can directly witness the operator, while an infinite
branch through the finitely branching tree constructed below can supply an
infinite witness. The minimally coherent reconstruction therefore quantifies only over
the represented indices \(0\le l<r\) for a finite word of length \(r\), and
over every \(l\ge0\) for an infinite word. That domain restriction is
handbook-supplied typing of the source's two cases, not text printed in the
display.

The source observes that a grammar can be normalized so every production has
at most one terminal symbol, at a constant-factor size increase. Its worked
example is

\[
 N_0\longrightarrow a_1a_2N_0.
\]

It generates the alternating infinite terminal word, and
\(N_0(\mathit{True},P)\) holds at the first point iff \(P\) holds at every
even position. This sentence conflicts with the displayed zero-based
semantics. The generated terminals are \(a_1,a_2,a_1,a_2,\ldots\), and the
clause tests the first argument at offsets \(0,2,\ldots\) and the second
argument \(P\) at offsets \(1,3,\ldots\). Thus the literal constructor requires
\(P\) at odd offsets. Replacing “even” by “odd,” swapping the arguments, or
reindexing positions from one would remove the mismatch, but the article
chooses none of those repairs. The conference version prints the same parity
sentence, so this is not a journal-only transcription change.

The journal's replacement proof chain following that stated correction is:

1. The journal enlarges `SF(f)` for a grammar operator to include the same
   argument tuple headed by every nonterminal of that grammar, then closes the
   set under negation.
2. It defines a labelled finitely branching tree
   \(\Gamma(S,j,N_i)\) for a regular-operator formula. Its root is labelled
   \(N_i(f_1,\ldots,f_n)\). A node at depth \(l\) labelled
   \(N_k(f_1,\ldots,f_n)\) has a child labelled
   \(N_r(f_1,\ldots,f_n)\) for every production \(N_k\to a_pN_r\) whose
   selected argument satisfies \(S,s_{j+l}\models f_p\). The tree records
   continuing productions; terminal productions are handled by the separate
   finite-witness condition.
3. **Lemma 5.1, pp. 745--746.** A negated regular-operator formula holds iff
   there is no finite generated witness string and the tree \(\Gamma\) is
   finite. The forward implication uses König's infinity lemma to
   rule out an infinite tree, and the reverse implication separates finite
   and infinite generated witnesses.
4. If a negated regular-operator formula holds at \(s_j\) and its finite tree
   has maximum depth \(d\), the source calls it *fulfilled before* \(s_m\) for
   every \(m\ge j+d\). This is a source-defined proof obligation, not a new
   temporal connective.
5. **Lemma 5.2, p. 746.** Take \(S,i,p,f,S'\) with every hypothesis of
   Lemma 4.6 and additionally require every subformula
   \(\neg N_u(f_1,\ldots,f_n)\in[s_i]_{S,f}\) to be fulfilled before
   \(s_{i+p}\). Then the lemma inherits both conclusions of Lemma 4.6 for
   every \(g\in SF(f)\):
   \[
   \begin{array}{ll}
   \forall k<i+p&
   S,s_k\models g\Longleftrightarrow S',s'_k\models g,\\
   \forall k\ge i&
   S',s'_k\models g\Longleftrightarrow S',s'_{k+p}\models g.
   \end{array}
   \]
   The paper prints the new positive and negated regular-operator induction
   cases; all other cases are inherited from Lemma 4.6.
6. **Theorem 5.3, pp. 746--747.** A satisfiable ETL formula has an ultimately
   periodic witness with
   \[
      l\le2^{1+\operatorname{card}(SF(f))},
      \qquad
      p\le c^{\operatorname{card}(SF(f))}
   \]
   for some constant \(c\), equal types one period apart, and both every
   outstanding `U`-formula and every outstanding negated regular-operator
   formula fulfilled before the next loop copy. The proof refines the
   reduction argument with at most
   \(4^{\operatorname{card}(SF(g))}\) equivalence classes carrying the
   frontier information for \(\Gamma\).
7. **Theorem 5.4, pp. 747--748.** Satisfiability and determination of truth in
   an \(R\)-structure are PSPACE-complete for ETL. Grammars are part of the
   input. Here the journal reuses \(n\) for total encoded input length. Since
   this note reserves \(n\) for terminal count and constructor arity, write
   \(\ell_{\mathrm{in}}\) for that independent source variable:
   \(\ell_{\mathrm{in}}\) is exactly the length of the complete encoded
   formula-and-grammar input. It is an eliminable metalinguistic size
   parameter, neither the constructor arity nor the fragment notation
   \(L(O_1,\ldots,O_k)\); the quantities differ whenever a fixed-arity grammar
   occurs in a longer encoded input. The distinction is needed for the space
   estimate, where the journal's bound becomes
   \(\operatorname{card}(SF(f))\le2\ell_{\mathrm{in}}\). With \(A\) and \(B\) the
   current and next guessed truth sets, the exact positive rule is
   \[
   \begin{split}
   N_j(f_1,\ldots,f_n)\in A\Longleftrightarrow
   &\exists k\,\exists\ell\,[
     (N_j\to a_kN_\ell)\text{ is a production}\land
     f_k\in A\land N_\ell(f_1,\ldots,f_n)\in B]\\
   &{}\lor\exists k\,[
     (N_j\to a_k)\text{ is a production}\land f_k\in A],
   \end{split}
   \]
   For each negated formula \(\neg N_j(f_1,\ldots,f_n)\) in the loop-entry
   set, the source keeps
   \(\varphi(N_j(f_1,\ldots,f_n))\), initialized to \(\{N_j\}\), and updates
   it by
   \[
   \begin{split}
   \varphi_{\mathrm{next}}(N_j(f_1,\ldots,f_n))
   =\{N_\ell:\;&\exists N_r\,\exists k\,[
   (N_r\to a_kN_\ell)\text{ is a production}\land\\
   &N_r\in\varphi_{\mathrm{present}}(N_j(f_1,\ldots,f_n))
   \land f_k\in A]\}.
   \end{split}
   \]
   This \(\varphi\) is an eliminable metalinguistic finite set of
   nonterminals, unrelated to the structure valuation and distinct from the
   whole labelled tree \(\Gamma\): it records one successive depth layer and
   is used only for the finite-tree check. The machine requires it to become
   empty at some point within the guessed period. Together with the positive
   consistency rule and Lemma 5.1, that check excludes finite and infinite
   generated witnesses for the negated formula.

The article contains no Büchi-automaton translation. Its upper bounds are
obtained from small or ultimately periodic structures and on-the-fly
subformula information. An automata-theoretic proof from a later source must
not be attributed to this article.

- “Truth in an \(R\)-structure” is the source's existential path problem. A
  universal program-correctness statement uses its negated counterexample
  formula.
- `L(F)`'s size is `length(init)+card(range)`, not a finite-state-model
  cardinality.
- The acceptable-union sentence and literal Lemma 3.3 both print strict

  proof-supported non-strict correction must be labelled.

  reflexive reachability because a loopless singleton passes. The source rule,
  the concrete false-acceptance example, and the handbook-owned directed-cycle
  correction must remain distinct.

  \(2^{\operatorname{length}(g)}\). Closure size and realized-type count must
