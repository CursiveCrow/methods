### Independent reconstruction of the limiting argument

Expanding the declared operations gives

`P'(eta)(t) iff not exists a < t: forall z (a < z < t implies not eta(z))`.

This is equivalent to `forall a < t: exists z (a < z < t and eta(z))`.
The dual calculation gives `forall b > t: exists z (t < z < b and eta(z))`
for `F'`. These are strict accumulation conditions with vacuous truth at a
missing side of the order. They impose no test of eta at t. An adjacent cut
makes the inner universal in the negated witness condition true, so it makes
the corresponding limit false. Thus replacing these operators with ordinary
existential past/future would invalidate the construction.

The predecessor's ordered binary realization equivalence is available in both
associations. Its base has two ordered endpoints after the external guard is
applied; adding a constructor adds one strictly interior point and one interval.
Its L recurrence appends an endpoint to an ending realization, and its R
recurrence prepends an endpoint to a beginning realization. Consequently
`E+_sigma` and `E-_sigma` have precisely the meanings needed by Lemma 2,
including when the limiting future class is written with a Bp constituent.
The predecessor supplies a Bf pattern with the same word and proves its
equivalence on the ordered endpoints in use.

For the reverse past implication, fix a cut a < t. The first conjunct supplies
an entire provisional chain beginning at u0 in (a,t). If its last point is
below t, the desired chain is already obtained. Otherwise there is a greatest
k with uk < t, and `uk < t <= u(k+1)`. The suffix hypothesis at cut uk gives
all of `v1 < ... < vn` inside (uk,t). The sequence

`u0, ..., uk, v(k+1), ..., vn`

has n + 1 points. Its new edge lies strictly inside the old edge from uk to
u(k+1), hence inherits B(k + 1). Every other edge and every endpoint has its
correct original word index. In particular, discarding v1 through vk does not
shift any remaining predicate index. For k = 0 the entire old suffix is replaced;
for k = n − 1 just the old final point is replaced. At n = 1 these reduce to
one replacement endpoint. Equality u(k + 1) = t changes none of the strict
inclusions or predicate obligations.

For the reverse future implication, the first conjunct gives a provisional
chain ending at un in (t,b). If it is not already entirely above t, select the
least k with uk > t. Then `u(k−1) <= t < uk`, and the prefix hypothesis gives
`t < v0 < ... < v(n−1) < uk`. The sequence

`v0, ..., v(k−1), uk, ..., un`

has n + 1 correctly indexed points. Its new edge is contained in the old edge
from u(k−1) to uk and therefore has Bk. The cases k = 1 and k = n replace,
respectively, only the old first point and all points except the old last.
Equality u(k−1) = t and n = 1 are valid. The forward implications merely
delete a first or last point from a realization within the same cut interval.
Induction on interval count then produces exactly both stated recurrences.

This argument chooses extrema only from finite index sets, never from an
arbitrary subset of the time order. All new time points are supplied by a
quantified premise. It therefore applies, for example, at the limit point of
omega + 1 as well as on dense orders; it has no concealed density or order
completeness premise.

### Independent verification of the seven results

For relation structure, x ~ y and y ~ z supply both directed weak-comparison
chains needed for x ~ z. If x strictly exceeds y and y strictly exceeds z,
transitivity supplies x weakly above z; the hypothetical reverse comparison
would make z weakly above y, contradicting the second strict comparison.
Intersecting equivalence classes coincide by transitivity, including the empty
partition convention. If a in [x] and b in [y] witness a weakly above b,
the chain `x >= a >= b >= y` proves x weakly above y. This justifies arbitrary
representative substitution before using it to prove the quotient order.

For representation, the least-element induction makes a comparison only after
the remaining set is nonempty. Removing the least class Aj ensures that each
later class is above it; antisymmetry rules out the reverse direction for
distinct classes. Thus the classes strictly below Aj are exactly its j
predecessors. The rank counts classes, so changing the number of tied members
cannot alter the numeric rank. The procedure terminates after k removals.
For an empty set, the unique relation and function are empty and all required
equivalences are vacuous. For a singleton, completeness forces the diagonal
pair and every single assigned real value represents it. For a nonempty tied
set, the equality characterization forces precisely the constant functions.

For uniqueness, whenever u(x) = u(y), both weak comparisons hold, so v(x) =
v(y). Therefore f(u(x)) = v(x) is independent of the selected alternative.
Strict increase follows from the strict-comparison equivalence and determines
the order of distinct classes. Every attained u-value has an alternative and
therefore a forced image, proving uniqueness exactly on that attained domain.
Conversely, strict increase on a subset of the real line preserves and reflects
both equality and order, which proves the representation equivalence for v.

In the extension formula each interpolation denominator is positive and each
numerator is positive. Adjacent formulas agree at every shared endpoint. Any
a < b crosses finitely many pieces and accumulates a positive total increase.
The two tails have positive slopes. Replacing the lower tail's slope one by
slope two yields a different global extension with the same attained values;
the singleton and empty constructions also give two distinct extensions.
Order still constrains values outside the attained set, but no numerical
choice there is prescribed by the representation. If one reads the body's
wording pointwise, an interior unobserved point can receive either of two
distinct values strictly between its neighboring attained images and be joined
by positive linear pieces; either exterior ray can likewise be varied. Thus
that reading also satisfies the stated claim.

For maximal choice, failure of x weakly above y, together with completeness,
is exactly what makes y strictly above x. Finiteness supplies a largest
occupied class on each nonempty menu. Pairwise recovery requires reflexivity
as well as x weakly above y, and the proof explicitly provides it. For menu
restriction, choose a surviving original maximum z. A new maximum x is weakly
above z, and z is weakly above every element of the original menu, so
transitivity makes x an original maximum too. The surviving-maximum hypothesis
is necessary: in the tied example, restricting the full menu to {a,b,c}
leaves choice {c}, whereas the intersection with original choice {d,e} is
empty. The theorem includes exactly the condition that excludes this case.

In the tied example the three possible numerical levels exhaust every
comparison. The full menu and {a,c,d,e} meet their highest class in {d,e};
{a,b,c} meets its highest class in {c}; {a,b} consists entirely of its one
occupied class. For the cycle, missing pairs (a,c), (b,a), (c,b) disqualify
a, b, c respectively. A representing function would satisfy
`u(a) > u(b) > u(c) > u(a)`, which is impossible.

Finally, the affine contradiction uses three distinct attained levels, so it
does not overstate what can happen with only two levels. The gap and average
calculations compare two numerical representations of the same original
alternatives. The warning correctly identifies the absence of assumptions
about intensity, lotteries or expected utility. No inference from finite
ordinal representation to those additional structures is made.
