\section{Source casts, equality substitution and constructor redexes}
\label{sec:annex-p07-ch88-ordinary-checking}

\begin{annexitem}{annex:p7.ch88.ordinary-star}{thm:p07-ch88-ordinary-star}{Raw source rigidity before source type correctness}
\begin{proof}
Source-image reflection and raw confluence are already proved in
\cref{thm:p07-ch88-check-raw-reflection}. The atom star is normal.
If \(TE=_\beta\ast\), target confluence gives a reduction of
\(TE\) to star, and path reflection gives a source reduction of
\(E\) to star. Object substitution and compatible source reduction
preserve the object/logical class. Thus an object cannot be that
\(E\). A logical context is star or has an outer product, and
compatible reductions of a product never remove that head. Hence
\(E\) is literally star. No source sorting premise was used.

A source equality maps to target raw beta equality, so an equality
with star has the same literal other endpoint. If a source lambda
had type star, its target typing would by CC generation have a
product type beta-equal to star. That product head cannot disappear,
contradicting confluence. Thus no such lambda exists.
For \(MN:\ast\), source generation exposes function type
\([x:A]Q\), argument type \(A\), and the actual final conversion
chain from \([N/x]Q\) to star. Raw transport and rigidity make
\([N/x]Q\) literally star. Substitution of an object preserves
the two classes and the outer product head of a logical context,
so \(Q\) itself must be star. These are the actual generated
premises claimed; no source type-correctness theorem for \(A\)
has been manufactured.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p7.ch88.ordinary-context}{thm:p07-ch88-ordinary-context}{Changing one declaration and its dependent suffix}
\begin{proof}
Work in the proved named source correspondence and decode afterward.
Use ordinary-source thinning and substitution from
\cref{thm:p07-ch88-check-substitution}, and the actual smaller prefix
certificates of \cref{thm:p07-ch88-check-generation}.
Induct simultaneously on the given validity/typing/equality derivation,
for every suffix. Construct its target suffix oldest-first: each old
annotation certificate is an actual smaller subderivation, so its
induction gives the same certificate in the already changed older
prefix. Append that literal annotation by the source extension rule.
The initial changed declaration is permitted by the assumed actual
certificate for \(A'\), not by a target judgment. Hence every target
suffix and every needed binder extension is valid.

At projection of \(x\), target projection gives \(x:A'\).
Thin the base equality \(A\cong A'\) to this valid target context,
symmetrize it, and apply actual typing conversion to get \(x:A\).
Every other projection retains its literal annotation. Validity star
is the constructed target validity. Both extensions, both products
and abstraction use their annotation/body inductions; application
combines its two inductions; typing conversion combines the unchanged
typing and equality formulas in the changed context.
Equality reflexivity uses its transported typing/validity premise;
symmetry/transitivity combine their inductions. Product equality uses
the transported first annotation equality and body equality in its
first-domain extension. Lambda equality retains its body typing there.
Full application equality retains its application typing and both
child equalities. Beta equality retains the body and literal-domain
argument typings, so its same primitive instance is available.
Fresh local names ensure that the changed external declaration is
not shadowed. No raw beta equality was substituted for source equality.
The induction covers all source rules and produces actual derivations
in the unchanged, dependent suffix expressions.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p7.ch88.ordinary-equal-substitution}{thm:p07-ch88-ordinary-equal-substitution}{Full congruence in the first substituted context}
\begin{proof}
Induct on the source validity or typing derivation, with all suffixes.
The first substituted suffix is valid by the already proved single
substitution theorem. The two substitutions leave the same number
of suffix variables, so the compared expressions are scoped in that
first context. Names are fresh and fixed before indexed decoding.

A projection of the removed variable uses \(N\cong N'\) thinned
to the first valid suffix. Every other projection has identical raw
variable images; single substitution gives its left typing, and full
typed reflexivity gives the required equality. Star validity uses
context reflexivity in the first substituted environment. Extension
conclusions are again star there. In either product rule, the actual
smaller annotation certificate gives its two images' equality by
induction. Body induction uses the extended suffix and gives the
body equality in the first annotation's substituted environment.
These are precisely product congruence premises.

For abstraction use these same domain/body inductions and the actual
left body typing supplied by single substitution of the original
premise. This is the full abstraction congruence guard. For application
use the function/argument inductions and the actual left application
typing from single substitution. Full simultaneous application
congruence then gives the two entire substituted applications.
A final typing conversion has unchanged subject, so use its typing
premise induction; no equality of its arbitrary type endpoints is
needed to infer equality of the subject images. These are all common
validity/typing constructors. The primitive source substitution
composition identities identify each new conclusion literally after
indexed decoding. This induction needs neither type correctness nor
typing of a right endpoint in the first suffix. In particular it
does not claim that restricted proof arguments have full reflexivity.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p7.ch88.ordinary-product-injection}{thm:p07-ch88-ordinary-product-injection}{Flattening actual headed proofs and transporting their leaf bodies}
\begin{proof}
Standardize every product's local binder to the same fresh named
variable \(x\), using the proved indexed correspondence. Flatten
outer symmetry and transitivity into a finite path of outer primitive
leaves, retaining each leaf's actual proof. A reversed leaf retains
its original premise context; it is not assumed to have a body proof
in the other annotation's context.

At a product-congruence leaf from \([x:D]U\) to \([x:E]V\),
the actual premises are \(\Gamma\vdash D\cong E\) and
\(\Gamma[x:D]\vdash U\cong V\). Regularity of the second
premise supplies the actual annotation certificate for \(D\).
At reflexivity of a valid logical product, generation gives
\(\Gamma[x:D]\vdash U\), so context reflexivity gives its body
equality and regularity supplies \(D\)'s certificate. At reflexivity
of a typed object product, generation gives
\(\Gamma[x:D]\vdash U:\ast\), regardless of stripped outer
conversions; full reflexivity gives the body equality and its context
gives the same domain certificate. Reflexivity of \(D\) follows
from its actual certificate in either annotation role.

Start the domain accumulator with \(A\cong A\), derived from
the given certificate. Traverse the path. A forward leaf with current
domain \(D\) supplies \(D\cong E\), so compose the accumulator
to obtain \(A\cong E\). For a reverse leaf the current domain
is \(E\); symmetrizing its domain equality and composing gives
\(A\cong D\). Therefore, before using either orientation's body,
one has an actual equality between \(A\) and that leaf's original
first domain \(D\). Both \(A,D\) have actual certificates: the
former is assumed and the latter was extracted from that leaf.
Apply \cref{thm:p07-ch88-ordinary-context} to transport its body
equality from \(\Gamma[x:D]\) to \(\Gamma[x:A]\). Orient it
according to the path. Concatenate these transported body equalities
in this one fixed context. The first leaf supplies the initial body
edge directly; no unproved reflexivity at an arbitrary initial body
is inserted. A reflexivity-only path has its certified body reflexivity
as just described. At the end the two accumulators are precisely
\(A\cong B\) and \(P\cong Q\) in the asserted contexts.
Nothing required a source certificate for an intermediate right domain.

For logical endpoint products, source equality preserves the logical
class. All outer intermediate expressions are logical contexts.
Raw equality transport and persistent product heads exclude star
at an intermediate node. Full typed reflexivity, lambda/application
congruence and beta have object endpoints, so none is an outer rule
in this kind proof. The remaining context reflexivity, product,
symmetry and transitivity rules are exactly the headed path handled
above. Thus headedness is automatic in this kind case. For object
products it is not: beta can connect a product to an application.
The proof has not erased such excursions by declaration.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p7.ch88.ordinary-root}{thm:p07-ch88-ordinary-root}{The generated domain cast and actual result-type restoration}
\begin{proof}
Use ordinary source generation on \(R:\Delta\). It gives actual
\(\Gamma\vdash(\lambda x:A)M:[x:B]Q\),
\(\Gamma\vdash N:B\), and the actual final conversion chain from
\([N/x]Q\) to \(\Delta\). Generate that lambda typing in turn:
there is an actual body derivation \(\Gamma[x:A]\vdash M:P\)
and a conversion chain from \([x:A]P\) to \([x:B]Q\).
The body's environment supplies the actual certificate for \(A\).

If the function chain is empty, \(B=A,Q=P\) literally. Substitute
the argument in the body and reapply the final application chain.
Otherwise combine its actual equalities by transitivity. Since
\(\Delta\) is logical, preservation of source classes along the
application chain makes \([N/x]Q\) logical. Object substitution
preserves classes, so \(Q\) is logical. Preservation of classes
along the function chain then makes \(P\) logical too. Both product
types are thus logical products, and the preceding injection theorem
constructs \(\Gamma\vdash A\cong B\) and
\(\Gamma[x:A]\vdash P\cong Q\).

Symmetrize the domain equality and convert the actual \(N:B\)
derivation to \(N:A\). Now the source substitution theorem applies
to both the body typing and the extracted body equality. It supplies
\(\Gamma\vdash C:[N/x]P\) and
\(\Gamma\vdash[N/x]P\cong[N/x]Q\). Convert to the latter result
type and reapply the original final conversion chain to obtain
\(C:\Delta\). Full primitive beta equality uses the actual
\(M:P\) body and the newly obtained literal-domain \(N:A\),
giving \(R\cong C\). This is an actual source cast and proof,
not target product injectivity alone.

For a general result type the same derivation works when the function
chain has the asserted product-headed proofs; its empty case is
unchanged. With body/argument premises already at the literal domain,
common abstraction and application directly give \(R:[N/x]P\),
and source substitution directly gives \(C:[N/x]P\). Any actual
outer conversion chain is copied to that contractum proof. None
of these statements asserts arbitrary proof-valued function-chain
headedness or a general source type-uniqueness theorem.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p7.ch88.ordinary-application}{thm:p07-ch88-ordinary-application}{Actual equality of the two substituted codomains}
\begin{proof}
Apply equal substitution with empty suffix to the given typing or
validity of \(B\). This constructs
\([N/x]B\cong[N'/x]B\) in \(\Gamma\). Common application from
\(F:[x:A]B\) and \(N':A\) gives
\(FN':[N'/x]B\). Symmetrize the constructed equality and use
the actual typing-conversion rule to obtain the old type
\([N/x]B\). The given source body certificate is used, rather
than silently extracting it from an unproved general type-correctness
theorem for an arbitrary \(F\).
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p7.ch88.ordinary-example}{thm:p07-ch88-ordinary-example}{Every declaration and the nonnormal source casts}
\begin{proof}
Extend the empty context by \(A:\ast\) using logical extension.
Projection gives \(A:\ast\). In an \(u:A\) extension star is
valid, so logical-product formation gives \([u:A]\ast\) valid.
This licenses \(F\)'s logical declaration. Projection/thinning
retain \(A:\ast\), licensing \(a:A\). In the \(u:A\) extension,
projection gives \(F:[u:A]\ast\) and \(u:A\); application gives
\(Fu:\ast\). Object-product formation gives
\([u:A]Fu:\ast\), which licenses \(f\)'s object declaration.
All four extensions therefore satisfy the actual source guards.
For an explicit index witness, this environment is
\([A:\ast][F:[u:1]\ast][a:2][f:[u:3](3\,1)]\ast\).
At its outer depth, \(A,F,a,f\) are respectively \(4,3,2,1\),
and \(n=((\lambda v:4)1)2\),
\(B=3\,(((\lambda v:4)1)2)\), \(B'=3\,2\).

Project \(v:A\) in its valid extension, abstract, and apply to
\(a:A\) to get \(n:A\). Full beta equality gives \(n\cong a\)
from those same literal-domain premises. This beta instance is not
the restricted logical one: its body type \(A\) is an object.
Application of \(F\) to each argument gives \(B:\ast,B':\ast\).
Full reflexivity of \(F\) and simultaneous application congruence
give \(B\cong B'\), using the actual left application typing.
Application of \(f\) gives \(fn:B\) and \(fa:B'\). Symmetry
and typing conversion give \(fa:B\). Equivalently this is the
dependent codomain-transport theorem with body \(Fu:\ast\).

Type-extension with \(B:\ast\) gives the valid nonnormal
\(\Gamma[h:B]\). Type-extension with \(B':\ast\) gives its
replacement. Context conversion transports the actual old projection
\(h:B\); directly, project \(h:B'\), thin \(B'\cong B\) to
that valid context, and convert. Thus there is an explicit source
proof of the old judgment in the new context.

Abstraction gives \(t:T\). In the changed context use the just
constructed \(h:B\), so abstraction gives
\(t':[h:B']B\). Thin \(B:\ast\) to this valid changed context,
then full reflexivity gives \(B\cong B\) there. Combine it with
\(B'\cong B\) by product congruence to get
\([h:B']B\cong[h:B]B\). Typing conversion yields \(t':T\).
Finally full lambda congruence uses \(B\cong B'\), the old
projection typing \(h:B\) and its full reflexivity to give
\(t\cong t'\). The actual raw contraction \(n\to a\) lifts
through \(Fn\) and the lambda annotation, giving \(t\to t'\)
for full compatible beta. Since \(Fn\) contains that redex, the
old annotation and \(T\) are nonnormal and fail the necessary
normal-variant invariants. No source typing inverse, hypothetical
proof-domain inhabitant or arbitrary raw normalization was used.
\end{proof}
\end{annexitem}
