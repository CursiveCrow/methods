\chaptermark{Further Reading for Part 8}
\label{sec:p08-further-reading}

The following is the Part~8 domain reading route:
\begin{itemize}
  \item For intuitionistic semantics, proof theory, and intermediate logics,
        see \textcite{TroelstraVanDalen1988} and
        \textcite{ChagrovZakharyaschev1997}.
  \item For normal modal logic, correspondence, canonical models, and
        filtration, see \textcite{BlackburnDeRijkeVenema2001}; for
        neighborhood semantics, see \textcite{Pacuit2017}.
  \item For temporal and multi-agent epistemic logic, see
        \textcite{FaginHalpernMosesVardi1995}; for public announcements and
        broader dynamic epistemic logic, see
        \textcite{VanDitmarschVanDerHoekKooi2007}; for hybrid logic, see
        \textcite{ArecesTenCate2007}.
  \item For finite and standard many-valued semantics and t-norm logics, see
        \textcite{Hajek1998,CintulaHajekNoguera2011}; for the K3--LP--FDE
        comparison, see \textcite{OmoriWansing2017}.
  \item For relevance systems and their exact semantic boundaries, see
        \textcite{DunnRestall2002}; for linear logic and phase semantics, see
        \textcite{Girard1995}; for the associative Lambek calculus, see
        \textcite{Buszkowski2010}.
  \item For free logic and definite descriptions, see
        \textcite{Lambert1967,Russell1905}; for deontic logic, see
        \textcite{VonWright1951,McNamara2006}; for strict and variably strict
        conditionals, see \textcite{Stalnaker1968,Lewis1971,Lewis1973,Wen2019}.
  \item For paraconsistent consequence, see
        \textcite{Priest2006,OmoriWansing2017}; for da Costa's \(C_1\), see
        \textcite{daCosta1974}; for preferential and rational
        nonmonotonic consequence, see
        \textcite{KrausLehmannMagidor1990,LehmannMagidor1992}.
  \item For belief revision, default logic, circumscription, and
        autoepistemic logic, see respectively
        \textcite{AlchourronGardenforsMakinson1985,KatsunoMendelzon1991},
        \textcite{Reiter1980}, \textcite{McCarthy1980}, and
        \textcite{Moore1985}.
\end{itemize}

This is annotated navigation, not an authority transfer: every theorem and
system card retains its own exact source and proof status.
