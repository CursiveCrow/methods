% Editorial composite core of intensional Martin--Lof type theory. The sheet
% fixes a Russell-style predicative universe hierarchy and does not add
% univalence, equality reflection, quotient types, or extensional eta laws.
\calculussheet{sheet:mltt-intensional}{Intensional Martin--L\"of Type Theory Core}{Judgments: $\Gamma\;\mathsf{ctx}$, $\Gamma\vdash A\;\mathsf{type}$, $\Gamma\vdash a:A$, and judgmental equalities; contexts extend by $x:A$; type formers: dependent products $\Pi_{x:A}B$, dependent sums $\Sigma_{x:A}B$, intensional identity $\operatorname{Id}_A(a,b)$, and cumulative predicative Russell universes $\mathcal U_0:\mathcal U_1:\cdots$ closed under these formers; weakening and capture-avoiding substitution are admissible structural operations; equality: judgmental equality is an equivalence and congruence generated by the displayed computations, while identity types are propositions-as-types and no equality reflection is present.}
\noindent\emph{Source standing:} this rule sheet is an editorial composite,
not a verbatim presentation controlled by one metatheorem source.
Martin--L\"of supplies the intensional dependent-type core, with later standard
presentations used for the judgment and universe organization
\cite{MartinLof1984,NordstromPeterssonSmith1990,Hofmann1997}.  Abel--Coquand--
Dybjer controls only the narrower dependent-function/one-universe
normalization and typed-equality theorem stated in
Theorem~\ref{thm:p07-mltt-normalization-decision}; it does not certify this
sheet's Sigma, identity-type, or cumulative-hierarchy remainder
\cite{AbelCoquandDybjer2007}.

\noindent For judgments transported to one context \(\Delta\), define the
multi-sorted equality premise
\[
 \operatorname{Eq}_{\Delta}(A\;\mathsf{type},A'\;\mathsf{type})
   \;\defeq\; \Delta\vdash A\equiv A'\;\mathsf{type},
 \qquad
 \operatorname{Eq}_{\Delta}(a:A,a':A')
   \;\defeq\;
   \bigl(\Delta\vdash A\equiv A'\;\mathsf{type}\ \land\
         \Delta\vdash a\equiv a':A\bigr),
\]
where the second conjunct uses Conv to regard \(a':A'\) as a term of \(A\).
For each displayed formation or typing rule, write
\(P_1(\bar x),\ldots,P_k(\bar x)\Rightarrow J_c(\bar x)\) for its exact
dependent premise telescope and conclusion judgment.  If
\(\sigma,\tau:\Delta\to\Gamma\) are capture-avoiding substitutions with
componentwise judgmental equality in \(\Delta\), each \(\tau\)-premise is first
transported into the corresponding \(\sigma\)-instance using the equality
premises already established to its left.  Congruence is then the following
single multi-sorted schema in the common context \(\Delta\).
