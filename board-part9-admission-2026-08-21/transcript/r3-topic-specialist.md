### F1 — The LTL/Büchi product is ill-typed, and its advertised alphabet is not the finite formula alphabet

- **Severity:** must-fix / theorem-defining construction is not presently well formed.
- **Evidence:** The transition structure actually reused by Part IX is defined at `handbook/parts/p08/temporal-epistemic-supplement.tex:46-55` as \(\mathcal K=(S,R,V)\) with
  \[
    V:\mathsf{Prop}\longrightarrow\mathcal P(S).

  Thus \(V\) takes a proposition letter as input.  The Part-IX product instead supplies states to this function: its initial set contains \(\delta(q_0,V(s_0))\) at `handbook/parts/p09/logic-in-computer-science.tex:519-526`, and its edge relation uses \(\delta(q,V(t))\) at `handbook/parts/p09/logic-in-computer-science.tex:527-529`. The dependent correctness theorem at `handbook/parts/p09/logic-in-computer-science.tex:541-550` consequently has no well-formed product to which it can apply.
- **Additional exactness issue in the same construction:** `handbook/parts/p09/logic-in-computer-science.tex:521-522` gives the automaton alphabet as \(2^{\mathsf{Prop}}\), while the global propositional alphabet is the countably infinite set \(\mathsf{Prop}=\{p_n:n\in\mathbb N\}\) at `handbook/parts/p02/propositional-syntax-semantics.tex:20-27`.  The finite, effectively represented automaton needed for the printed construction instead uses the finite set of proposition letters occurring in the input formula.  The standard automata-theoretic presentation fixes a finite proposition set and labels each state by the subset true there; see the manuscript's controlling `VardiWolper1986` bibliography entry at `handbook/bib/handbook.bib:2262-2269` and the author-hosted scholarly exposition [Vardi, *Alternating Automata and Program Verification*](https://www.cs.rice.edu/~vardi/papers/istcs97rj.pdf).
- **Concrete harm:** even on the one-state structure \(S=\{s_0\}\), the displayed initial product set attempts to evaluate a function with domain \(\mathsf{Prop}\) at the state \(s_0\).  This is a type error before any accepting-cycle argument begins.  Moreover, an explicit transition table over the stated infinite alphabet is not the finite constructed object used by the stated size and running-time analysis.
- **Exact correction:** Let
  \[
    \mathsf{AP}(A)=\{p\in\mathsf{Prop}:p\text{ occurs in }A\},

    \ell_A(s)=\{p\in\mathsf{AP}(A):s\in V(p)\}.

### F2 — The ALC annex defines its redirection map on indirectly blocked nodes by a direct blocker they need not possess

- **Severity:** must-fix / a map used in a theorem marked `proved` is not total under the printed definitions.
- **Evidence:** The live blocking definition says that a nonroot node is *directly* blocked when its label is included in an ancestor label, and is merely *blocked* also when one of its ancestors is blocked (`handbook/parts/p09/logic-in-computer-science.tex:324-334`; equivalently `handbook/registry/calculi/tableaux-alc.tex:2,20-25`).  The annex nevertheless says, for every blocked node \(x\), to obtain \(u(x)\) by repeatedly replacing the node by “its direct blocker” (`handbook/annex/p09/proofs.tex:37-40`).  An indirectly blocked node need not itself satisfy the label-inclusion test and therefore need not have any direct blocker.
- **Minimal counterexample to definedness:** take a completion-tree segment \(r\to a\to b\).  Let \(\mathcal L(a)\subseteq\mathcal L(r)\), so \(a\) is directly blocked by \(r\), but choose \(\mathcal L(b)\) not included in any ancestor label.  Then \(b\) is blocked only because its ancestor \(a\) is blocked.  It has no direct blocker, so the first step in the displayed definition of \(u(b)\) is undefined.  Such a residual descendant is possible under the live dynamic policy: a node can acquire blocked status after descendants were generated because blocking is re-evaluated whenever labels grow (`handbook/parts/p09/logic-in-computer-science.tex:327-332`).
- **Concrete harm:** the proof begins its finite-model extraction with a purported map on completion nodes that is not defined on all of them.  The later assertion that replacement terminates because blockers are strict ancestors addresses infinite descent, not the missing first blocker.  This is a formal proof defect even though the underlying tableau theorem is repairable.
- **Exact correction:** Do not define \(u\) on every blocked completion node.  Let the model domain be the unblocked nodes as now, and define redirection only for a target \(y\) of a retained edge \(x\mathrel r y\) whose source \(x\) is unblocked.  Put \(\widehat y=y\) when \(y\) is unblocked; otherwise choose a directly blocking ancestor \(b(y)\) with \(\mathcal L(y)\subseteq\mathcal L(b(y))\) and put \(\widehat y=b(y)\).  This is total on the required targets: if the immediate predecessor \(x\) is unblocked, no proper ancestor of \(y\) is blocked, so a blocked \(y\) is directly, not merely indirectly, blocked, and every possible blocking ancestor is unblocked.  Interpret \(r\) using \((x,\widehat y)\) for these retained edges and use the same label inclusion in the existential and universal induction cases.  Equivalently, first prove this restricted-redirection lemma and state the domain of \(u\) accordingly.  The body sentence at `handbook/parts/p09/logic-in-computer-science.tex:336-343` should likewise say that targets of edges retained from unblocked sources are redirected, rather than suggesting that every indirectly blocked residual node requires a blocker map.
- **Status:** open.
