\chapter{Decidability and Complexity Tables}
\label{sec:p14-decidability-and-complexity}

A decision classification belongs to a specified question on specified
encoded inputs. The tables below distinguish changing the formula from
changing the structure, a finite structure from an unrestricted model,
and a terminating algorithm from a semidecision or a numerical certificate.
The cited destinations supply the definitions, procedures, reductions and
proofs; a lookup row does not change their proof standing
\cite{AroraBarak2009,AbiteboulHullVianu1995,BlackburnDeRijkeVenema2001}.

\section{The exact decision problem and input representation}
\label{sec:p14-dc-input}

\begin{hbdefinition}{def:p14-dc-instance}{The problem specified by a complexity row}
A decision problem is a set of finite input words under one declared
encoding. A row specifies the language or theory, the semantic model class,
the yes question, the objects fixed in advance, the objects supplied as
input, the size measure, and the reduction convention for completeness.
Invalid encodings are no instances unless a promise is explicitly stated.
Write \(L_{\mathrm{bit}}\) for total encoded bit length.
A count of syntax nodes, literal occurrences, arithmetic operations or
graph vertices is a separate measure.

Polynomial-time intertranslations preserve classes under polynomial-time
many-one reductions. A linear algorithm on an expanded syntax tree does
not imply a linear algorithm on a compressed circuit describing that tree.
For logarithmic-space completeness the translation itself must use
logarithmic workspace; polynomial-time equivalence alone is insufficient.
\end{hbdefinition}

The encoding qualifications in Table~\ref{tab:p14-dc-encoding} belong to the
stated bounds. A size parameter is not made constant merely because it is
small in a worked example.

\begin{hbtheorem}{thm:p14-dc-finite-cpl}{proved=annex:p14.dc.finite-cpl}{The finite classical reductions and their complexity}
For finite classical propositional inputs, validity, finite semantic
consequence and logical equivalence are coNP-complete under polynomial-time
many-one reductions. Finite consequence is validity of
\((\bigwedge\Gamma)\to A\), and equivalence is validity of \(A\leftrightarrow B\).
The transformations have polynomial encoded size, including shared atom
identifiers. These reductions use classical truth conditions; they are not
unqualified theorems for every nonclassical implication or designated-value
semantics. No finite-input classification is assigned to an arbitrarily
presented infinite premise set.
\end{hbtheorem}

\begin{hbtheorem}{thm:p14-dc-horn}{proved=annex:p14.dc.horn}{The Horn completeness lower bound}
Horn-CNF satisfiability is P-complete under logarithmic-space many-one
reductions in the standard explicit finite encoding. The forward-chaining
upper bound remains the literal-reference bound in
\cref{thm:p02-horn-sat}; this result does not turn that operation count into
a linear bit-time claim for every atom representation.
\end{hbtheorem}

\section{Data, formula, query, and combined complexity}
\label{sec:p14-dc-measures}

\begin{hbdefinition}{def:p14-dc-measures}{Which input varies}
Data complexity fixes the query/specification and charges the database/model.
Expression complexity fixes the data and charges the expression. Combined
complexity charges all supplied components. Containment instead varies two
queries and quantifies over their possible databases. For each fixed query a
polynomial data algorithm may have a query-dependent exponent; it need not
give one polynomial in combined input length
\cite{Vardi1982,AbiteboulHullVianu1995}.
\end{hbdefinition}

\section{Finite and unrestricted structures}

unbounded size exists or whether a sentence holds in every structure.

for its exact language and model class. An ultimately periodic infinite word
