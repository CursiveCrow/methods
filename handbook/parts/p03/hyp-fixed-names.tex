\section{The least admissible set and its fixed names}
\label{sec:p03-hyp-fixed-names}

The natural numbers used as formula indices do not themselves name every
infinitary formula. The required naming result is stronger: every element
of the least admissible set containing \(\omega\) has a unique
\(\Sigma_1\) name that continues to name that same element in suitable
set-theoretic end extensions. This supplies the fixed formula codes
needed by the abstract-logic representation argument.

\begin{hblemma}{thm:p03-adm-constructible-recursion}{proved=annex:p3.adm.15}{Constructible levels}
The constructible hierarchy and a coherent canonical well-order of its
levels have uniformly \(\Sigma_1\), provably functional construction
relations in KPU with Infinity. Only pure sets occur in these levels.
If \(B\) is a transitive admissible set with \(\omega\in B\), and
\(\beta\) is its ordinal height, then \(L_\beta\subseteq B\) and
\(L_\beta\) is admissible with \(\omega\) as an element.
The assertion applies also when \(B\) is an admissible set over
urelements.
\end{hblemma}

\begin{hbtheorem}{thm:p03-hyp-least}{proved=annex:p3.adm.16}{The least admissible set containing \(\omega\)}
There is a least transitive admissible set containing \(\omega\) as an
element. It is \(L_\alpha\), where \(\alpha\) is the least ordinal
such that \(L_\alpha\) is admissible and contains \(\omega\).
It is countable externally. Write \(\mathrm{HYP}=L_\alpha\).
Every transitive admissible set containing \(\omega\), including one
over urelements, contains this pure admissible set.
\end{hbtheorem}

\begin{hbtheorem}{thm:p03-hyp-fixed-names}{proved=annex:p3.adm.17}{Fixed names}
For every \(a\in\mathrm{HYP}\) there is a parameter-free
\(\Sigma_1\)-formula \(\sigma_a(x)\) such that
\(\mathrm{HYP}\models\sigma_a(a)\), and KPU with Infinity proves
that at most one object satisfies \(\sigma_a\).
Consequently, in every KPU end extension of \(\mathrm{HYP}\), the
unique object satisfying \(\sigma_a\) is the embedded copy of \(a\).
The extension need not be externally well founded.
An end extension here preserves membership on the old domain and adds
no new member to an old set; it is required to satisfy the stated
set-theoretic axioms. Arbitrary relational extensions without those
axioms are not covered.
\end{hbtheorem}
