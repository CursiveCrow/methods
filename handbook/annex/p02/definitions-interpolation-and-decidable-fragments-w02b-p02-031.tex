\section{Proofs for validity, finite satisfiability and semi-conservative reductions}
\label{sec:annex-p02-w02b-p02-031-validity-finsat}

Sets of formulas are sets of codes under the fixed effective coding of
\cref{sec:decision-hierarchy-01}, and the classes \(\mathrm{Val}\),
\(\mathrm{Fin\text{-}sat}\) and \(\mathrm{Non\text{-}sat}\) are those of
Definition~\ref{def:p02-w02-p02-036-classes}.  Under that coding the set
\(\mathrm{FO}\) of codes of formulas, and for each finite signature the set of
codes of its sentences, are decidable.

\begin{annexitem}{annex:p02-w02b-p02-031-val-to-finsat}{thm:p02-w02b-p02-031-val-to-finsat}{Validity reduces to finite satisfiability}
\begin{proof}
Let \(R_{\Lang}\) be a binary relation symbol of \(\Lang\).

\emph{Step 1: universal closure.}  For a formula \(\varphi\) whose free
variables, listed in their order of first occurrence, are
\(x_1,\ldots,x_p\), put \(\varphi^{\forall}\defeq\forall x_1\cdots\forall
x_p\,\varphi\), a sentence.  The free variables are computed by recursion on
\(\varphi\), so \(\varphi\mapsto\varphi^{\forall}\) is computable.  By the
satisfaction clause for \(\forall\), applied \(p\) times, and
\cref{lem:fol-coincidence}, a structure \(\mathfrak A\) satisfies
\(\varphi^{\forall}\) iff \(\mathfrak A,s\entails\varphi\) for every
assignment \(s\).  Hence \(\varphi\) is valid iff \(\varphi^{\forall}\) is
true in every structure for the signature of \(\varphi\).  By
\cref{lem:reduct-invariance} this does not change when larger signatures are
admitted: a structure for a larger signature satisfies \(\varphi^{\forall}\)
iff its reduct does, and every structure for the signature of \(\varphi\) has
expansions.  So \(\varphi\in\mathrm{Val}\) iff \(\varphi^{\forall}\) belongs
to the set \(V\) of codes of valid sentences.

\emph{Step 2: a recognizer.}  The set \(V\) is computably enumerable
(\cref{thm:fol-validity-enumerable}), so some Turing machine \(\mathcal R\)
recognizes it (\cref{thm:ce-equivalent-forms}): its input alphabet contains
the digits \(0,1\), since it is run on binary numerals, and its computation
on \(\operatorname{bin}(n)\) reaches \(q_{\mathrm{acc}}\) iff \(n\in V\).

\emph{Step 3: the map.}  For \(\varphi\in\mathrm{FO}\) put
\[
 F(\varphi)\defeq
 \bigl(\psi_{\mathcal R,\operatorname{bin}(\ulcorner\varphi^{\forall}\urcorner)}
 \bigr)^{\sharp}[R_{\Lang}/E],
\]
where \(\ulcorner\varphi^{\forall}\urcorner\) is the code of
\(\varphi^{\forall}\).  The run signature \(\Lang_{\mathcal R}\) of
Definition~\ref{def:p02-w02-p02-036-run-sentence} consists of binary and unary
relation symbols, so the path translation of
Definition~\ref{def:p02-w02-p02-036-gadget} applies to its sentences, and
\(F(\varphi)\) is an \(\{R_{\Lang}\}\)-sentence, hence a member of
\(\operatorname{Sent}(\Lang)\).  The map \(F\) is computable as a composite
of computable maps: \(\varphi\mapsto\varphi^{\forall}\) by Step~1; the coding
and \(n\mapsto\operatorname{bin}(n)\); \(w\mapsto\psi_{\mathcal R,w}\) for the
fixed machine \(\mathcal R\) by Lemma~\ref{thm:p02-w02-p02-036-run-sentence};
\(\chi\mapsto\chi^{\sharp}\) by
Lemma~\ref{thm:p02-w02-p02-036-gadget}(3); and the letter-for-letter renaming.

\emph{Step 4: the equivalence.}  For \(\varphi\in\mathrm{FO}\), write
\(w_{\varphi}\defeq\operatorname{bin}(\ulcorner\varphi^{\forall}\urcorner)\).
Then
\[
\begin{aligned}
 \varphi\in\mathrm{Val}
 &\iff \ulcorner\varphi^{\forall}\urcorner\in V
   &&\text{(Step 1)}\\
 &\iff \text{the computation of }\mathcal R\text{ on }w_{\varphi}
   \text{ reaches }q_{\mathrm{acc}}
   &&\text{(Step 2)}\\
 &\iff \psi_{\mathcal R,w_{\varphi}}\in
   \mathrm{Fin\text{-}sat}(\operatorname{Sent}(\Lang_{\mathcal R}))
   &&\text{(Lemma~\ref{thm:p02-w02-p02-036-run-sentence})}\\
 &\iff \psi_{\mathcal R,w_{\varphi}}^{\sharp}\in
   \mathrm{Fin\text{-}sat}(\operatorname{Sent}(\{E\}))
   &&\text{(Lemma~\ref{thm:p02-w02-p02-036-gadget}(3))}\\
 &\iff F(\varphi)\in\mathrm{Fin\text{-}sat}(\operatorname{Sent}(\Lang))
   &&\text{(Lemma~\ref{thm:p02-w02-p02-036-transfer}).}
\end{aligned}
\]

\emph{Step 5: the consequence.}  Suppose a machine decides
\(\mathrm{Fin\text{-}sat}(\operatorname{Sent}(\Lang))\).  Given a number
\(n\), reject if \(n\notin\mathrm{FO}\); otherwise compute \(F(n)\) and give
the decider's answer on it.  By Step~4 this procedure halts on every input and
accepts exactly the codes of valid formulas.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-semi-inseparable}{thm:p02-w02b-p02-031-semi-inseparable}{Semi-conservative reductions preserve inseparability}
\begin{proof}
Suppose, for a contradiction, that a decidable set \(W\) separates
\(\mathrm{Non\text{-}sat}(Y)\) from \(\mathrm{Fin\text{-}sat}(Y)\), that is,
\(\mathrm{Non\text{-}sat}(Y)\subseteq W\) and
\(W\cap\mathrm{Fin\text{-}sat}(Y)=\varnothing\).  Put
\(W'\defeq\{n\in X:f(n)\in W\}\).  The set \(W'\) is decidable: given \(n\),
decide whether \(n\in X\), which is possible because \(X\) is recursive;
if so, compute \(f(n)\), which halts because \(f\) halts on every member of
\(X\); then decide whether \(f(n)\in W\).

If \(\psi\in\mathrm{Non\text{-}sat}(X)\), then
\(f(\psi)\in\mathrm{Non\text{-}sat}(Y)\subseteq W\) by clause~1 of
Definition~\ref{def:p02-w02b-p02-031-semi-conservative}, so \(\psi\in W'\).
If \(\psi\in\mathrm{Fin\text{-}sat}(X)\), then
\(f(\psi)\in\mathrm{Fin\text{-}sat}(Y)\) by clause~2, and this set is disjoint
from \(W\), so \(f(\psi)\notin W\) and \(\psi\notin W'\).  Hence \(W'\)
separates \(\mathrm{Non\text{-}sat}(X)\) from \(\mathrm{Fin\text{-}sat}(X)\),
against the hypothesis.  So no decidable set separates
\(\mathrm{Non\text{-}sat}(Y)\) from \(\mathrm{Fin\text{-}sat}(Y)\).  By the
symmetry remark after Definition~\ref{def:p02-w02-p02-036-inseparable}, no
decidable set separates them in the other order either, and the two sets are
recursively inseparable.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-semi-not-conservative}{thm:p02-w02b-p02-031-semi-not-conservative}{A semi-conservative reduction without a conservative one}
\begin{proof}
Each of \(X\) and \(Y\) is the set of one fixed code, so membership is decided
by comparing a number with that code; and the constant map \(f\), which sends
the code of \(\prec_K\) to the code of \(\exists x\,Kxx\), is computable.

By Lemma~\ref{thm:p02-w02-p02-036-infinity-axiom}, \(\prec_K\) has a model and
has no finite model.  Hence \(\mathrm{Non\text{-}sat}(X)=\varnothing\) and
\(\mathrm{Fin\text{-}sat}(X)=\varnothing\), and both clauses of
Definition~\ref{def:p02-w02b-p02-031-semi-conservative} hold for \(f\), since
the image of the empty set is empty.  So \(f\) is a semi-conservative
reduction from \(X\) to \(Y\).

Let \(g:X\to Y\) be any map.  Its only possible value is \(\exists x\,Kxx\),
so \(g(\prec_K)=\exists x\,Kxx\).  The one-element structure with domain
\(\{0\}\) and \(K=\{(0,0)\}\) satisfies \(\exists x\,Kxx\), so \(g(\prec_K)\)
is finitely satisfiable, whereas \(\prec_K\) is not.  The required
biconditional for finite satisfiability therefore fails at
\(\psi=\prec_K\), and no such \(g\) exists.
\end{proof}
\end{annexitem}

The next items use the indices \(W_e\) of
Convention~\ref{def:p02-w02b-p02-031-we}.  Two facts about machine codes are
taken from the proof of Lemma~\ref{thm:p02-w02-p02-036-halting}
(\cref{annex:p02-w02-p02-036-halting}).  By its part~(a), a Turing machine
whose input alphabet contains the digits has a valid code whose decoded machine
accepts, rejects and diverges on every binary word exactly as the given machine
does; and when the machine is obtained from decoded machines by a fixed
construction on their finite tables, that code is a computable function of the
given codes.  By its part~(b), there is a map \(w\), computable on \(V\), such
that \(M_{w(e)}\) on the empty input accepts, rejects or diverges exactly as
\(M_e\) does on \(\operatorname{bin}(e)\).  A relation on numbers is called
computably enumerable when the set of codes of its tuples is.  Computably
enumerable relations are closed under conjunction and disjunction: for a
conjunction run recognizers of the two members one after the other, for a
disjunction run them alternately, one step at a time, and accept as soon as
one accepts.

\begin{annexitem}{annex:p02-w02b-p02-031-code-constructions}{thm:p02-w02b-p02-031-code-constructions}{Index constructions}
\begin{proof}
Throughout, \(n_\varnothing\) is a fixed valid code of a machine that never
accepts, for instance one whose start state moves right forever; so
\(W_{n_\varnothing}=\varnothing\).

\emph{Item 1.}  Let \(A\) be computably enumerable.  By
\cref{thm:ce-equivalent-forms} some Turing machine recognizes \(A\): run on
\(\operatorname{bin}(n)\), it reaches \(q_{\mathrm{acc}}\) iff \(n\in A\).
Since it is run on binary numerals, its input alphabet contains both digits.
Part~(a) gives a valid code \(e\) with \(M_e\) accepting exactly the same
binary words, so \(W_e=A\).

\emph{Item 2.}  Fix a machine \(T_h\) that computes \(h\): started on
\(\operatorname{bin}(\operatorname{code}_2(c,n))\), it halts with
\(\operatorname{bin}(h(c,n))\) as its output.  For \(i\in V\) and
\(c\in\mathbb N\) let \(N_{i,c}\) be the machine that, on input
\(\operatorname{bin}(n)\), proceeds in three phases.  First it replaces
\(\operatorname{bin}(n)\) by \(\operatorname{bin}(\operatorname{code}_2(c,n))\),
the digits of \(c\) being written into its table in the way the digits of
\(e\) are written into the table of \(N_e\) in part~(b).  Then it runs
\(T_h\), with the halting state of \(T_h\) redirected to the third phase.  In
the third phase it returns the head to cell \(0\) and enters the start state of
\(M_i\), whose transitions it contains.  Its table is obtained from the tables
of \(T_h\) and \(M_i\) and the binary digits of \(c\) by a fixed construction.
Let \(a(i,c)\) be the code that part~(a) gives for \(N_{i,c}\), and put
\(a(i,c)\defeq n_\varnothing\) for \(i\notin V\).  Since \(V\) is decidable,
\(a\) is total computable.  For \(i\in V\), \(M_{a(i,c)}\) accepts
\(\operatorname{bin}(n)\) iff \(M_i\) accepts \(\operatorname{bin}(h(c,n))\), so
\(W_{a(i,c)}=\{n:h(c,n)\in W_i\}\).  For \(i\notin V\) both sides are empty,
because \(W_i=\varnothing\).

\emph{Item 3.}  For \(i,j\in\mathbb N\) let \(N'_{i,j}\) be the machine
that, on input \(\operatorname{bin}(n)\), simulates the computations of
\(M_i\) and \(M_j\) on \(\operatorname{bin}(n)\) alternately, one step of each
in turn, a computation of an invalid code being treated as one that never
halts.  It enters its accepting state as soon as the simulated computation of
\(M_i\) reaches \(q_{\mathrm{acc}}\), and its rejecting state as soon as that
of \(M_j\) reaches \(q_{\mathrm{acc}}\), whichever happens first; a simulated
computation that reaches \(q_{\mathrm{rej}}\) is no longer advanced.  The
simulation of one step of a decoded machine is a step of the universal machine
of \cref{thm:universal-computation} applied to a stored table, so
\(N'_{i,j}\) is obtained from the tables of \(M_i\) and \(M_j\) by a fixed
construction; let \(d(i,j)\in V\) be the code that part~(a) gives for it.
Then \(d\) is total computable.  If \(n\in W_i\setminus W_j\), the simulation
of \(M_i\) reaches \(q_{\mathrm{acc}}\) after finitely many steps and that of
\(M_j\) never does, so \(M_{d(i,j)}\) accepts \(\operatorname{bin}(n)\).  If
\(n\in W_j\setminus W_i\), it rejects \(\operatorname{bin}(n)\) by the same
argument.  If \(n\notin W_i\cup W_j\), neither simulated computation reaches
\(q_{\mathrm{acc}}\); since \(N'_{i,j}\) enters a halting state only when one
of them does, its computation on \(\operatorname{bin}(n)\) never halts, and by
part~(a) neither does that of \(M_{d(i,j)}\).

\emph{Item 4.}  Apply item~2 to \(h(c,z)\defeq\operatorname{code}_2(c,z)\),
obtaining \(a\), and put \(s(i)\defeq a(i,i)\).  Then \(s\) is total
computable, \(s(i)\in V\) for every \(i\) (both \(n_\varnothing\) and the
codes of part~(a) are valid), and
\[
 W_{s(i)}=\{z:\operatorname{code}_2(i,z)\in W_i\}.
\]
For \(m\in\mathbb N\) let \((m_0,m_1)\) be the unique pair with
\(m=\operatorname{code}_2(m_0,m_1)\), and put
\[
 \Theta'\defeq\{m\in\mathbb N:\operatorname{code}_2(s(m_0),m_1)\in\Theta\}.
\]
The map \(m\mapsto\operatorname{code}_2(s(m_0),m_1)\) is total computable,
since the inverse of \(\operatorname{code}_2\) is computable, and it many-one
reduces \(\Theta'\) to \(\Theta\); so \(\Theta'\) is computably enumerable by
the preservation lemma for many-one reductions in \cref{sec:universal-reductions-02}.  By item~1 there is \(d_0\in V\) with
\(W_{d_0}=\Theta'\).  Put \(k\defeq s(d_0)\in V\).  For every \(z\),
\[
\begin{aligned}
 z\in W_k
 &\iff \operatorname{code}_2(d_0,z)\in W_{d_0}=\Theta'\
 &\iff \operatorname{code}_2(s(d_0),z)\in\Theta
 \iff \operatorname{code}_2(k,z)\in\Theta .
\end{aligned}
\]
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-eff-transfer}{thm:p02-w02b-p02-031-eff-transfer}{Elementary properties of effective inseparability}
\begin{proof}
\emph{Item 1.}  If \(B\subseteq W_i\), \(A\subseteq W_j\) and \(W_i\cap
W_j=\varnothing\), the hypothesis applied to the pair \((j,i)\) gives
\(p(j,i)\notin W_j\cup W_i\).

\emph{Item 2.}  Suppose a decidable \(R\) separates \(A\) from \(B\).  Then
\(R\) and \(\mathbb N\setminus R\) are computably enumerable
(\cref{thm:ce-equivalent-forms}), so by
\cref{thm:p02-w02b-p02-031-code-constructions}(1) there are \(i,j\) with
\(W_i=R\) and \(W_j=\mathbb N\setminus R\).  Now \(A\subseteq W_i\),
\(B\subseteq W_j\) and \(W_i\cap W_j=\varnothing\), so
\(p(i,j)\notin W_i\cup W_j=\mathbb N\), which is impossible.

\emph{Item 3.}  If \(A'\subseteq W_i\), \(B'\subseteq W_j\) and \(W_i\cap
W_j=\varnothing\), then \(A\subseteq W_i\) and \(B\subseteq W_j\), so
\(p(i,j)\notin W_i\cup W_j\).

\emph{Item 4.}  Apply \cref{thm:p02-w02b-p02-031-code-constructions}(2) to
\(h'(c,n)\defeq h(n)\), obtaining \(a\), and put \(b(i)\defeq a(i,0)\); so
\(W_{b(i)}=h^{-1}(W_i)\).  Define \(p'(i,j)\defeq h(p(b(i),b(j)))\), a total
computable function.  Suppose \(C\subseteq W_i\), \(D\subseteq W_j\) and
\(W_i\cap W_j=\varnothing\).  Then \(A\subseteq h^{-1}(C)\subseteq W_{b(i)}\),
\(B\subseteq h^{-1}(D)\subseteq W_{b(j)}\), and
\(W_{b(i)}\cap W_{b(j)}=h^{-1}(W_i\cap W_j)=\varnothing\).  Hence
\(q\defeq p(b(i),b(j))\notin W_{b(i)}\cup W_{b(j)}\), that is, \(h(q)\notin
W_i\) and \(h(q)\notin W_j\).  So \(p'(i,j)=h(q)\notin W_i\cup W_j\), and
\(p'\) witnesses that \(C\) and \(D\) are effectively inseparable; they are
disjoint by hypothesis.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-eff-halting}{thm:p02-w02b-p02-031-eff-halting}{Effectively inseparable halting problems}
\begin{proof}
The sets \(D_{\mathrm{rej}}\) and \(D_{\mathrm{acc}}\) are disjoint, because a
computation of a deterministic machine reaches at most one halting state, at
which it stops.  Let \(d\) be the function of
\cref{thm:p02-w02b-p02-031-code-constructions}(3); it witnesses the effective
inseparability of \(D_{\mathrm{rej}}\) and \(D_{\mathrm{acc}}\).  Suppose
\(D_{\mathrm{rej}}\subseteq W_i\), \(D_{\mathrm{acc}}\subseteq W_j\) and
\(W_i\cap W_j=\varnothing\), and put \(n\defeq d(i,j)\in V\).  If \(n\in W_i\),
then \(n\notin W_j\), so \(M_n\) accepts \(\operatorname{bin}(n)\) and \(n\in
D_{\mathrm{acc}}\subseteq W_j\), a contradiction.  If \(n\in W_j\), then
\(n\notin W_i\), so \(M_n\) rejects \(\operatorname{bin}(n)\) and \(n\in
D_{\mathrm{rej}}\subseteq W_i\), again a contradiction.  So \(n\notin W_i\cup
W_j\).

For the halting problems, extend the map \(w\) of part~(b) to all of
\(\mathbb N\) by \(w(e)\defeq n_\varnothing\) for \(e\notin V\), with
\(n_\varnothing\) as in \cref{annex:p02-w02b-p02-031-code-constructions}; it
stays computable since \(V\) is decidable.  If \(e\in D_{\mathrm{rej}}\), then
\(M_{w(e)}\) rejects the empty input, so \(w(e)\in H_1\); if \(e\in
D_{\mathrm{acc}}\), then \(w(e)\in H_2\).  The sets \(H_1\) and \(H_2\) are
disjoint.  By \cref{thm:p02-w02b-p02-031-eff-transfer}(4), \(H_1\) and \(H_2\)
are effectively inseparable.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-eff-classes}{thm:p02-w02b-p02-031-eff-classes}{Unsatisfiable and finitely satisfiable formulas are effectively inseparable}
\begin{proof}
Let \(R\) be a binary relation symbol of \(\Lang\) and
\(X_{\Lang}\defeq\operatorname{Sent}(\Lang)\).

\emph{The pair for \(\Lang\).}  For \(e\in V\) put
\(r(e)\defeq(\rho_{M_e,\prec})^{\sharp}[R/E]\), the sentence used in the proof
of \cref{thm:p02-w02-p02-036-inseparable}, and for \(e\notin V\) let \(r(e)\)
be a fixed member of \(X_{\Lang}\).  As shown there, \(r\) is computable, and
\(e\in H_1\) gives \(r(e)\in\mathrm{Non\text{-}sat}(X_{\Lang})\) while \(e\in
H_2\) gives \(r(e)\in\mathrm{Fin\text{-}sat}(X_{\Lang})\).  These two classes
are disjoint.  By \cref{thm:p02-w02b-p02-031-eff-halting} and
\cref{thm:p02-w02b-p02-031-eff-transfer}(4) they are effectively inseparable.

\emph{All formulas.}  By the remark after
Definition~\ref{def:p02-w02-p02-036-classes},
\(\mathrm{Non\text{-}sat}(X_{\Lang})\subseteq\mathrm{Non\text{-}sat}\) and
\(\mathrm{Fin\text{-}sat}(X_{\Lang})\subseteq\mathrm{Fin\text{-}sat}\), and
the latter two sets are disjoint.  By
\cref{thm:p02-w02b-p02-031-eff-transfer}(3), \(\mathrm{Non\text{-}sat}\) and
\(\mathrm{Fin\text{-}sat}\) are effectively inseparable.

\emph{Enumerability.}  A formula \(\psi\) is unsatisfiable iff \(\neg\psi\) is
satisfied by every structure under every assignment, that is, iff
\(\neg\psi\in\mathrm{Val}\).  The set \(\mathrm{Val}\) is computably
enumerable: by Steps~1 and~2 of the proof of
\cref{thm:p02-w02b-p02-031-val-to-finsat}, \(\psi\in\mathrm{Val}\) iff
\(\psi^{\forall}\) belongs to the computably enumerable set of codes of valid
sentences, and \(\psi\mapsto\psi^{\forall}\) is computable.  So
\(\mathrm{Non\text{-}sat}\) is many-one reducible to \(\mathrm{Val}\), by
\(\psi\mapsto\neg\psi\) on \(\mathrm{FO}\) and a fixed code of a non-valid
formula elsewhere, and it is computably enumerable by
the preservation lemma for many-one reductions in \cref{sec:universal-reductions-02}.  For \(\mathrm{Fin\text{-}sat}\): a
formula \(\psi\) has a finite signature and finitely many free variables.  For
each \(n\geq1\) there are finitely many structures for that signature with
domain \(\{0,\ldots,n-1\}\), each given by finite tables for its symbols, and
finitely many assignments of its free variables into that domain; whether such
a structure satisfies \(\psi\) under such an assignment is computed by the
recursion of the satisfaction clauses, in which every quantifier ranges over
\(n\) elements.  The procedure that, given \(\psi\in\mathrm{FO}\), runs through
\(n=1,2,\ldots\) and these finitely many pairs for each \(n\), and accepts when
a satisfying pair appears, halts exactly on the members of
\(\mathrm{Fin\text{-}sat}\); on numbers outside the decidable set
\(\mathrm{FO}\) it is made to run forever.  So \(\mathrm{Fin\text{-}sat}\) is
computably enumerable.

\emph{The pair for \(X\).}  Extend \(f\) to a total computable function on
\(\mathbb N\) by sending every number outside \(\mathrm{FO}\) to \(f\) of a
fixed formula.  By
Definition~\ref{def:p02-w02b-p02-031-semi-conservative},
\(f(\mathrm{Non\text{-}sat})\subseteq\mathrm{Non\text{-}sat}(X)\) and
\(f(\mathrm{Fin\text{-}sat})\subseteq\mathrm{Fin\text{-}sat}(X)\), and these
two classes are disjoint.  By the previous paragraphs and
\cref{thm:p02-w02b-p02-031-eff-transfer}(4) they are effectively inseparable.
They are computably enumerable as intersections of the decidable set \(X\) with
the computably enumerable sets \(\mathrm{Non\text{-}sat}\) and
\(\mathrm{Fin\text{-}sat}\).
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-embedding}{thm:p02-w02b-p02-031-embedding}{Embedding into an effectively inseparable pair}
\begin{proof}
Let \(p\) witness the effective inseparability of \(R_1\) and \(R_2\).  Apply
\cref{thm:p02-w02b-p02-031-code-constructions}(2) to the total computable
function \(h(c,y)\defeq\operatorname{code}_2(c_0,\operatorname{code}_2(c_1,y))\),
where \(c=\operatorname{code}_2(c_0,c_1)\), obtaining \(a\), and put
\(t(k,x,b)\defeq a(k,\operatorname{code}_2(x,b))\).  Since
\(\operatorname{code}_3(x,b,y)=\operatorname{code}_2(x,\operatorname{code}_2(b,y))\),
\(t\) is total computable and
\[
 W_{t(k,x,b)}=\{y:\operatorname{code}_3(x,b,y)\in W_k\}.
 \tag{1}
\]
Write \(\gamma(k,x)\defeq p\bigl(t(k,x,1),t(k,x,2)\bigr)\), a total computable
function.

\emph{The fixed point.}  Let \(\Theta\) be the set of numbers
\(\operatorname{code}_2(k,\operatorname{code}_3(x,b,y))\) such that
\[
\begin{aligned}
 &\bigl(b=1\land(y\in R_1\lor(x\in P_2\land y=\gamma(k,x)))\bigr)\
 &\quad\lor
 \bigl(b=2\land(y\in R_2\lor(x\in P_1\land y=\gamma(k,x)))\bigr).
\end{aligned}
\]
The conditions \(b=1\), \(b=2\) and \(y=\gamma(k,x)\) are decidable, the
conditions \(y\in R_1\), \(y\in R_2\), \(x\in P_1\), \(x\in P_2\) are
computably enumerable, and the inverses of the tuple codes are computable; so
\(\Theta\) is computably enumerable by the closure under conjunction and
disjunction.  By \cref{thm:p02-w02b-p02-031-code-constructions}(4) there is
\(k\in V\) with \(W_k=\{z:\operatorname{code}_2(k,z)\in\Theta\}\).  Fix this
\(k\) and put \(i(x)\defeq t(k,x,1)\), \(j(x)\defeq t(k,x,2)\) and
\(g(x)\defeq\gamma(k,x)=p(i(x),j(x))\).  The function \(g\) is total
computable.  By~(1) and the choice of \(k\), for every \(x\),
\[
 W_{i(x)}=\begin{cases}R_1\cup\{g(x)\}&x\in P_2,\\ R_1&x\notin P_2,\end{cases}
 \qquad
 W_{j(x)}=\begin{cases}R_2\cup\{g(x)\}&x\in P_1,\\ R_2&x\notin P_1.\end{cases}
 \tag{2}
\]

\emph{Three cases.}  Fix \(x\); since \(P_1\) and \(P_2\) are disjoint,
exactly one of the following holds.
\begin{enumerate}
\item \(x\notin P_1\cup P_2\).  By~(2), \(W_{i(x)}=R_1\) and
  \(W_{j(x)}=R_2\): disjoint sets containing \(R_1\) and \(R_2\).  So
  \(g(x)=p(i(x),j(x))\notin R_1\cup R_2\).
\item \(x\in P_1\).  By~(2), \(W_{i(x)}=R_1\) and
  \(W_{j(x)}=R_2\cup\{g(x)\}\).  Suppose \(g(x)\notin R_1\).  Then
  \(W_{i(x)}\cap W_{j(x)}=(R_1\cap R_2)\cup(R_1\cap\{g(x)\})=\varnothing\),
  and the two sets contain \(R_1\) and \(R_2\), so
  \(g(x)\notin W_{i(x)}\cup W_{j(x)}\); but \(g(x)\in W_{j(x)}\).  Hence
  \(g(x)\in R_1\).
\item \(x\in P_2\).  By~(2), \(W_{i(x)}=R_1\cup\{g(x)\}\) and
  \(W_{j(x)}=R_2\).  If \(g(x)\notin R_2\), the two sets are disjoint and
  contain \(R_1\) and \(R_2\), so \(g(x)\notin W_{i(x)}\); but \(g(x)\in
  W_{i(x)}\).  Hence \(g(x)\in R_2\).
\end{enumerate}

\emph{Conclusion.}  Case~2 gives \(P_1\subseteq g^{-1}(R_1)\).  Conversely, if
\(g(x)\in R_1\), then case~1 is excluded, and case~3 would give \(g(x)\in R_2\),
which is disjoint from \(R_1\); so \(x\in P_1\).  Hence \(P_1=g^{-1}(R_1)\),
and \(P_2=g^{-1}(R_2)\) by the same argument with cases 2 and~3 exchanged.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-gurevich}{thm:p02-w02b-p02-031-gurevich}{Gurevich: semi-conservative reductions from FO suffice}
\begin{proof}
Let \(f\) be a semi-conservative reduction from \(\mathrm{FO}\) to \(X\).

\emph{Step 1: the four sets.}  Put
\[
\begin{aligned}
 P_1&\defeq\mathrm{Non\text{-}sat}\cup(\mathbb N\setminus\mathrm{FO}),&
 P_2&\defeq\mathrm{Fin\text{-}sat},\
 R_1&\defeq\mathrm{Non\text{-}sat}(X)\cup(\mathbb N\setminus X),&
 R_2&\defeq\mathrm{Fin\text{-}sat}(X).
\end{aligned}
\]
By \cref{thm:p02-w02b-p02-031-eff-classes}, \(\mathrm{Non\text{-}sat}\),
\(\mathrm{Fin\text{-}sat}\), \(\mathrm{Non\text{-}sat}(X)\) and
\(\mathrm{Fin\text{-}sat}(X)\) are computably enumerable, and the complements of
the decidable sets \(\mathrm{FO}\) and \(X\) are decidable; so all four sets are
computably enumerable, a union of two such sets being recognized by running two
recognizers alternately.  \(P_1\cap P_2=\varnothing\), because an unsatisfiable
formula has no finite model and \(\mathrm{Fin\text{-}sat}\subseteq\mathrm{FO}\);
likewise \(R_1\cap R_2=\varnothing\).  By
\cref{thm:p02-w02b-p02-031-eff-classes}, \(\mathrm{Non\text{-}sat}(X)\) and
\(\mathrm{Fin\text{-}sat}(X)\) are effectively inseparable, so \(R_1\) and
\(R_2\) are effectively inseparable by
\cref{thm:p02-w02b-p02-031-eff-transfer}(3).

\emph{Step 2: the embedding.}  By \cref{thm:p02-w02b-p02-031-embedding} there
is a total computable \(g\) with \(P_1=g^{-1}(R_1)\) and \(P_2=g^{-1}(R_2)\).

\emph{Step 3: correction into \(X\).}  Choose an unsatisfiable formula
\(\bot_0\in\mathrm{FO}\), for instance \(\forall x\,(Px\land\neg Px)\) with
\(P\) unary, and put \(x_1\defeq f(\bot_0)\); by clause~1 of
Definition~\ref{def:p02-w02b-p02-031-semi-conservative},
\(x_1\in\mathrm{Non\text{-}sat}(X)\).  For \(\psi\in\mathrm{FO}\) define
\[
 G(\psi)\defeq
 \begin{cases}
  g(\psi)&\text{if }g(\psi)\in X,\\
  x_1&\text{otherwise.}
 \end{cases}
\]
\(G\) maps \(\mathrm{FO}\) into \(X\) and is recursive, since \(g\) is total
computable and \(X\) is decidable.

\emph{Step 4: \(G\) respects the three classes.}  Let \(\psi\in\mathrm{FO}\).
\begin{itemize}
\item If \(\psi\in\mathrm{Non\text{-}sat}\), then \(\psi\in P_1\), so
  \(g(\psi)\in R_1\): either \(g(\psi)\in\mathrm{Non\text{-}sat}(X)\), and then
  \(G(\psi)=g(\psi)\), or \(g(\psi)\notin X\), and then \(G(\psi)=x_1\).  In
  both cases \(G(\psi)\in\mathrm{Non\text{-}sat}(X)\).
\item If \(\psi\in\mathrm{Fin\text{-}sat}\), then \(g(\psi)\in R_2\subseteq
  X\), so \(G(\psi)=g(\psi)\in\mathrm{Fin\text{-}sat}(X)\).
\item If \(\psi\in\mathrm{Inf\text{-}axioms}\), then \(\psi\notin P_1\cup P_2\),
  because \(\psi\in\mathrm{FO}\) is satisfiable and has no finite model.  So
  \(g(\psi)\notin R_1\cup R_2\).  As \(g(\psi)\notin R_1\), \(g(\psi)\in X\)
  and \(G(\psi)=g(\psi)\), and \(g(\psi)\notin\mathrm{Non\text{-}sat}(X)\cup
  \mathrm{Fin\text{-}sat}(X)\).  Since the three classes partition \(X\),
  \(G(\psi)\in\mathrm{Inf\text{-}axioms}(X)\).
\end{itemize}

\emph{Step 5: \(G\) is conservative.}  The three classes partition
\(\mathrm{FO}\) and partition \(X\), and by Step~4 \(G\) maps each class of
\(\mathrm{FO}\) into the corresponding class of \(X\).  Hence for
\(\psi\in\mathrm{FO}\): \(\psi\) is satisfiable iff \(\psi\notin
\mathrm{Non\text{-}sat}\) iff \(G(\psi)\notin\mathrm{Non\text{-}sat}(X)\) iff
\(G(\psi)\) is satisfiable; and \(\psi\) is finitely satisfiable iff
\(\psi\in\mathrm{Fin\text{-}sat}\) iff \(G(\psi)\in\mathrm{Fin\text{-}sat}(X)\)
iff \(G(\psi)\) is finitely satisfiable.  In each chain the middle equivalence
holds from left to right by Step~4 applied to the class of \(\psi\), and from
right to left by Step~4 applied to the other two classes.  So \(G\) is a
conservative reduction from \(\mathrm{FO}\) to \(X\), and \(X\) is a
conservative reduction class
(Definition~\ref{def:p02-w02-p02-036-conservative}).
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-ex-2-1-40-2}{thm:p02-w02b-p02-031-ex-2-1-40-2}{The second item of Exercise 2.1.40 for \(X=\mathrm{FO}\)}
\begin{proof}
The class \(Y\) is a recursive subclass of \(\mathrm{FO}\) that receives the
semi-conservative reduction \(f\) from \(\mathrm{FO}\).  The proof of
\cref{thm:p02-w02b-p02-031-gurevich}, with \(Y\) in the role of \(X\), produces
a recursive \(G:\mathrm{FO}\to Y\) that satisfies both biconditionals for every
\(\psi\in\mathrm{FO}\) (its Step~5).  Take \(g\defeq G\).
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-two-register-simulation}{thm:p02-w02b-p02-031-two-register-simulation}{Two-register machines simulate Turing machines}
\begin{proof}
The proof passes through programs with four registers.  A
\emph{\(k\)-register program}, for \(k\in\{2,4\}\), is defined as in
Definition~\ref{def:p02-w02b-p02-031-two-register} except that its states form
an arbitrary finite set with a designated start state and designated stop
states that carry no instruction, its instructions \((i,r,j)\) and
\((i,r,j,k)\) name registers \(r\in\{1,\ldots,k\}\), and its configurations are
\((i,c_1,\ldots,c_k)\).  A two-register program in the sense of the definition
is obtained from a \(2\)-register program with two stop states by numbering
its states, the start state by \(0\) and the stop states by \(1\) and \(2\).

\emph{Step 0: three loops.}  Let \(X\neq Y\) be registers and \(\ell\) a
state.  Fresh states are used for every occurrence of a loop.
\begin{enumerate}
\item[(M1)] For \(f\geq1\), the loop \(\mathrm{MOVE}_f(X\to Y;\ell)\) has
  entry \(\mu_0\) and states \(\mu_0,\ldots,\mu_f\), with instructions
  \((\mu_0,X,\ell,\mu_1)\), \((\mu_l,Y,\mu_{l+1})\) for \(1\leq l<f\), and
  \((\mu_f,Y,\mu_0)\).  \emph{Claim:} from a configuration with state
  \(\mu_0\), \(X=x\) and \(Y=y\), the computation reaches state \(\ell\) with
  \(X=0\), \(Y=y+fx\) and every other register unchanged, and before that it
  is only in the states \(\mu_0,\ldots,\mu_f\).  By induction on \(x\).  If
  \(x=0\), the instruction of \(\mu_0\) leads to \(\ell\) in one step.  If
  \(x>0\), it subtracts \(1\) from \(X\) and goes to \(\mu_1\); then \(f\)
  additions to \(Y\) lead through \(\mu_1,\ldots,\mu_f\) back to \(\mu_0\),
  with \(X=x-1\) and \(Y=y+f\); the induction hypothesis gives \(\ell\) with
  \(X=0\) and \(Y=y+f+f(x-1)=y+fx\).
\item[(M2)] For \(b\geq0\), the loop \(\mathrm{ADD}_b(X;\ell)\) is empty, with
  entry \(\ell\), if \(b=0\); otherwise it has states \(\nu_1,\ldots,\nu_b\)
  with instructions \((\nu_l,X,\nu_{l+1})\) for \(l<b\) and
  \((\nu_b,X,\ell)\), and entry \(\nu_1\).  It reaches \(\ell\) after \(b\)
  steps, with \(X\) increased by \(b\) and the other registers unchanged.
\item[(M3)] For \(p\geq2\) and states \(\ell_0,\ldots,\ell_{p-1}\), the loop
  \(\mathrm{DIVMOD}_p(X\to Y;\allowbreak\ell_0,\ldots,\ell_{p-1})\) has entry \(\pi_0\)
  and states \(\pi_0,\ldots,\pi_p\), with instructions
  \((\pi_l,X,\ell_l,\pi_{l+1})\) for \(l<p\) and \((\pi_p,Y,\pi_0)\).
  \emph{Claim:} from state \(\pi_0\) with \(X=x\) and \(Y=y\), the computation
  reaches \(\ell_{x\bmod p}\) with \(X=0\), \(Y=y+\lfloor x/p\rfloor\) and
  every other register unchanged, and before that it is only in the states
  \(\pi_0,\ldots,\pi_p\).  By induction on \(\lfloor x/p\rfloor\).  If
  \(x<p\), the instructions of \(\pi_0,\ldots,\pi_{x-1}\) subtract \(1\)
  each, and at \(\pi_x\) the register \(X\) is \(0\), so the next state is
  \(\ell_x\).  If \(x\geq p\), the instructions of \(\pi_0,\ldots,\pi_{p-1}\)
  subtract \(p\) in total and lead to \(\pi_p\), which adds \(1\) to \(Y\) and
  returns to \(\pi_0\), with \(X=x-p\) and \(Y=y+1\); since \((x-p)\bmod
  p=x\bmod p\) and \(\lfloor(x-p)/p\rfloor=\lfloor x/p\rfloor-1\), the
  induction hypothesis gives the claim.
\end{enumerate}
Loops are chained by taking the exit state of one as the entry of the next.

\emph{Step 1: numbers for tape halves.}  Let \(\mathcal T=(Q,\mathcal
A_{\mathrm{in}},\mathcal A_{\mathrm{tape}},\delta,q_0,q_{\mathrm{acc}},
q_{\mathrm{rej}})\), put \(s\defeq\lvert\mathcal A_{\mathrm{tape}}\rvert+1\geq2\),
and fix a bijection \(\nu\) from \(\mathcal A_{\mathrm{tape}}\) onto
\(\{0,\ldots,s-2\}\) with \(\nu(\sqcup)=0\).  For a tape function \(T\) and a
head position \(h\) put
\[
 \lambda(T,h)\defeq\sum_{i\geq1}\nu(T(h-i))\,s^{i-1},\qquad
 \rho(T,h)\defeq\sum_{i\geq0}\nu(T(h+i))\,s^{i}.
\]
The sums are finite, since \(T\) has finite nonblank support and
\(\nu(\sqcup)=0\).  All base-\(s\) digits of these numbers are at most
\(s-2\), and \(\rho(T,h)\bmod s=\nu(T(h))\).  Suppose \((q,T,h)\longrightarrow
_{\mathcal T}(q',T',h')\) with \(\delta(q,T(h))=(q',b,d)\), and write
\(\lambda,\rho,\lambda',\rho'\) for the numbers of \((T,h)\) and \((T',h')\).
Since \(\rho=\nu(T(h))+s\sum_{i\geq0}\nu(T(h+1+i))s^{i}\) and
\(\lambda=\nu(T(h-1))+s\sum_{i\geq1}\nu(T(h-1-i))s^{i-1}\), and \(T'\) differs
from \(T\) only at \(h\), where it is \(b\):
\begin{itemize}
\item if \(d=R\), then \(h'=h+1\), \(\lambda'=\nu(b)+s\lambda\) and
      \(\rho'=\lfloor\rho/s\rfloor\);
\item if \(d=L\), then \(h'=h-1\), \(\lambda'=\lfloor\lambda/s\rfloor\) and
      \(\rho'=(\lambda\bmod s)+s\,\nu(b)+s^{2}\lfloor\rho/s\rfloor\).
\end{itemize}
For instance, for \(d=L\) the new right half starts at cell \(h-1\), which
holds \(T(h-1)\), with digit \(\lambda\bmod s\), continues with cell \(h\),
which holds \(b\), and then with cells \(h+1,h+2,\ldots\), whose number is
\(\lfloor\rho/s\rfloor\).  For an input word \(w\) the initial configuration
\((q_0,T_w,0)\) has \(\lambda=0\) and \(\rho=\rho_0(w)\defeq\sum_{i<\lvert
w\rvert}\nu(w(i))\,s^{i}\).

\emph{Step 2: a four-register program.}  The program \(P_{\mathcal T}\) has the
registers \(1,2,3,4\), named \(L,R,A,C\).  For every \(q\in Q\) it has a state
\([q]\); the states \([q_{\mathrm{acc}}]\) and \([q_{\mathrm{rej}}]\) are its stop
states and \([q_0]\) is its start state.  For non-halting \(q\), the state
\([q]\) is the entry of \(\mathrm{DIVMOD}_s(R\to A;\allowbreak\ell_{q,0},\ldots,
\ell_{q,s-1})\).  The state \(\ell_{q,s-1}\) gets the instruction
\((\ell_{q,s-1},C,\ell_{q,s-1})\); it is never reached, by the digit bound of
Step~1.  For \(a\in\mathcal A_{\mathrm{tape}}\) with
\(\delta(q,a)=(q',b,d)\), the state \(\ell_{q,\nu(a)}\) is the entry of the
following chain of loops, ending in \([q']\):
\begin{itemize}
\item if \(d=R\): \(\mathrm{MOVE}_s(L\to R)\), \(\mathrm{MOVE}_1(R\to L)\),
      \(\mathrm{ADD}_{\nu(b)}(L)\), \(\mathrm{MOVE}_1(A\to R)\),
      \(\mathrm{ADD}_1(C)\);
\item if \(d=L\): \(\mathrm{MOVE}_s(A\to R)\), \(\mathrm{ADD}_{\nu(b)}(R)\),
      \(\mathrm{DIVMOD}_s(L\to A;\allowbreak\ell'_{q,a,0},\ldots,\allowbreak\ell'_{q,a,s-1})\), and
      from each \(\ell'_{q,a,e}\) the chain \(\mathrm{MOVE}_s(R\to L)\),
      \(\mathrm{ADD}_{e}(L)\), \(\mathrm{MOVE}_1(L\to R)\),
      \(\mathrm{MOVE}_1(A\to L)\), \(\mathrm{ADD}_1(C)\).
\end{itemize}
\emph{Claim:} if \((q,T,h)\to_{\mathcal T}(q',T',h')\), then the
computation of \(P_{\mathcal T}\) from \(([q],\lambda,\rho,0,t)\) reaches
\(([q'],\lambda',\rho',0,t+1)\), and in between it is only in loop states, none
of the form \([q'']\).  Indeed, by (M3) the first loop leads to
\(\ell_{q,\nu(a)}\), \(a=T(h)\), with \(R=0\) and \(A=\lfloor\rho/s\rfloor\).
If \(d=R\), (M1) and (M2) give in turn \((L,R)=(0,s\lambda)\), then
\((s\lambda,0)\), then \(L=s\lambda+\nu(b)=\lambda'\), then \(A=0\) and
\(R=\lfloor\rho/s\rfloor=\rho'\), then \(C=t+1\).  If \(d=L\), they give
\(A=0\) and \(R=s\lfloor\rho/s\rfloor\), then \(R=s\lfloor\rho/s\rfloor+
\nu(b)\); (M3) gives \(L=0\), \(A=\lfloor\lambda/s\rfloor\) and the exit
\(\ell'_{q,a,e}\) with \(e=\lambda\bmod s\); then \(R=0\) and
\(L=s^{2}\lfloor\rho/s\rfloor+s\nu(b)\), then \(L=\rho'\), then \(L=0\) and
\(R=\rho'\), then \(A=0\) and \(L=\lfloor\lambda/s\rfloor=\lambda'\), then
\(C=t+1\).  The values \(\lambda'\) and \(\rho'\) are those of Step~1.

\emph{Step 3: from four registers to two.}  Let \(p_1,p_2,p_3,p_4\) be
\(2,3,5,7\), and for \(\vec c\in\mathbb N^{4}\) put \(\langle\vec
c\rangle\defeq2^{c_1}3^{c_2}5^{c_3}7^{c_4}\geq1\).  By unique factorization,
\(p_r\) divides \(\langle\vec c\rangle\) iff \(c_r\geq1\), and then
\(\langle\vec c\rangle/p_r\) is \(\langle\vec c\rangle\) with \(c_r\)
decreased by \(1\); also \(p_r\langle\vec c\rangle\) is \(\langle\vec
c\rangle\) with \(c_r\) increased by \(1\).  The \(2\)-register program
\(M_{\mathcal T}\) has a state \([i]\) for each state \(i\) of
\(P_{\mathcal T}\) and replaces each instruction:
\begin{itemize}
\item \((i,r,j)\) by the chain \(\mathrm{MOVE}_{p_r}(1\to2)\),
      \(\mathrm{MOVE}_1(2\to1)\) from \([i]\) to \([j]\);
\item \((i,r,j,k)\) by \(\mathrm{DIVMOD}_{p_r}(1\to2;\allowbreak\zeta_0,\ldots,
      \zeta_{p_r-1})\) with entry \([i]\), followed from \(\zeta_0\) by
      \(\mathrm{MOVE}_1(2\to1)\) ending in \([k]\), and from \(\zeta_l\),
      \(l\geq1\), by \(\mathrm{MOVE}_{p_r}(2\to1)\) and \(\mathrm{ADD}_l(1)\)
      ending in \([j]\).
\end{itemize}
The stop states of \(P_{\mathcal T}\) become clearing states:
\([q_{\mathrm{rej}}]\) gets \(([q_{\mathrm{rej}}],1,\mathbf 1,
[q_{\mathrm{rej}}])\) and \([q_{\mathrm{acc}}]\) gets
\(([q_{\mathrm{acc}}],1,\mathbf 2,[q_{\mathrm{acc}}])\), where \(\mathbf 1\) and
\(\mathbf 2\) are the stop states of \(M_{\mathcal T}\).  Number the states:
\([q_0]\) by \(0\), \(\mathbf 1\) by \(1\), \(\mathbf 2\) by \(2\), and the
others by distinct numbers from \(3\) on.  \emph{Claim:} if
\(P_{\mathcal T}\) passes in one step from \((i,\vec c)\) to \((i',\vec c')\),
then \(M_{\mathcal T}\) passes from \(([i],\langle\vec c\rangle,0)\) to
\(([i'],\langle\vec c'\rangle,0)\) through loop states only.  For an addition
instruction, (M1) twice gives \(([j],p_r\langle\vec c\rangle,0)\).  For a
subtraction instruction, (M3) leads to \(\zeta_l\) with
\(l=\langle\vec c\rangle\bmod p_r\), register \(1\) empty and register \(2\)
equal to \(\lfloor\langle\vec c\rangle/p_r\rfloor\).  If \(c_r\geq1\), then
\(l=0\) and (M1) gives \(([k],\langle\vec c\rangle/p_r,0)\).  If \(c_r=0\),
then \(l\geq1\), and (M1), (M2) give \(([j],p_r\lfloor\langle\vec
c\rangle/p_r\rfloor+l,0)=([j],\langle\vec c\rangle,0)\).  Both agree with the
step of \(P_{\mathcal T}\).  From a clearing state with register \(1\) equal to
\(n\) and register \(2\) empty, the computation subtracts \(n\) times and then
enters \(\mathbf 1\), respectively \(\mathbf 2\), in the configuration
\((1,0,0)\), respectively \((2,0,0)\).

Put \(m_{\mathcal T}(w)\defeq\langle0,\rho_0(w),0,0\rangle=3^{\rho_0(w)}\);
so \(m_{\mathcal T}(\varepsilon)=3^{0}=1\).

\emph{Step 4: the four properties.}  Let \(c_t=(q_t,T_t,h_t)\) be the
configurations of \(\mathcal T\) on \(w\) and put \(N_t\defeq\langle
\lambda(T_t,h_t),\rho(T_t,h_t),0,t\rangle\).  Then \(N_0=m_{\mathcal T}(w)\).
By the claims of Steps 2 and~3 and induction on \(t\), the computation of
\(M_{\mathcal T}\) from \((0,N_0,0)=([q_0],N_0,0)\) passes through
\(([q_t],N_t,0)\) for every \(t\) for which \(c_t\) exists, in this order,
and between two consecutive ones it is only in loop states, which are
neither stop states nor clearing states.  If \(\mathcal T\) halts at time
\(k\) with \(q_k=q_{\mathrm{rej}}\), the computation reaches the clearing state
\([q_{\mathrm{rej}}]\) with register \(2\) empty, then \((1,0,0)\), where it
ends; if \(q_k=q_{\mathrm{acc}}\), it ends in \((2,0,0)\).  If \(\mathcal T\)
never halts, the computation passes through infinitely many configurations
\(([q_t],N_t,0)\), so it is infinite; it is never in a clearing state, so
never in a stop state; and \(N_t\geq7^{t}\), so its register contents are
unbounded.  This proves property~4.  A stop state is entered only from a
clearing state when register \(1\) is empty, and register \(2\) is empty
throughout a clearing loop; this proves property~3.  The left-to-right
directions of properties 1 and~2 follow: if the computation reaches
\((1,0,0)\), then \(\mathcal T\) halts, by property~4, and it does not accept,
since otherwise the computation would end in \((2,0,0)\) and a computation
contains at most one configuration in a stop state; so \(\mathcal T\) rejects.
The case of \((2,0,0)\) is the same with the roles exchanged.

\emph{Computability.}  The program \(P_{\mathcal T}\), its translation and the
numbering are produced from the finite table of \(\mathcal T\) by the fixed
steps above, and \(w\mapsto3^{\rho_0(w)}\) is computable.

\emph{The start from \((0,0,0)\).}  Let \(M^{0}_{\mathcal T}\) be
\(M_{\mathcal T}\) with the state \(0\) renamed to a number \(e_0\) not used
by \(M_{\mathcal T}\), together with a new start state \(0\) carrying
\((0,1,e_0)\).  From \((0,0,0)\) it passes in one step to \((e_0,1,0)\), and
from there its computation is that of \(M_{\mathcal T}\) from
\((0,m_{\mathcal T}(\varepsilon),0)=(0,1,0)\) with \(0\) renamed to \(e_0\).
The extra first configuration is not in a stop state and does not affect
whether the register contents are bounded, so properties 1--4 hold for
\(w=\varepsilon\).
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-register-reduction}{thm:p02-w02b-p02-031-register-reduction}{Reduction property of the register-machine formulas}
\begin{proof}
Let \(\mathcal R\) be the set of configurations of the computation of \(M\)
from \((0,m,0)\), and \(\mathrm{Val}_{\mathcal R}\) the set of its register
contents.  Call a conjunct of \(\alpha_{M,m}\) a \emph{\(u\)-clause} if it
contains \(u\); by Definition~\ref{def:p02-w02b-p02-031-register-formulas} the
\(u\)-clauses are \(K_iuy\to K_juy\), \(K_iyu\to K_jyu\), \(K_0uu\) or
\(A_0uu\), and \(\neg K_1uu\), and they contain neither \(x\) nor \(v\); the
other conjuncts do not contain \(u\).

\emph{(a) Zeros and successors in a model.}  Let \(\mathfrak B\) be a model of
\(\beta\) with domain \(B\).  If \(\beta=\beta_{M,\prec,m}\), choose \(z\in B\)
witnessing \(\exists u\), and for every \(c\in B\) choose \(f(c)\in B\)
witnessing \(\exists v\) for \(x\mapsto c\); then \(\mathfrak B\entails
\alpha_{M,m}[z,c,f(c),d]\) for all \(c,d\in B\).  If
\(\beta=\beta^{+}_{M,\prec,m}\), choose for every \(c\in B\) elements
\(z_c,f(c)\) with \(\mathfrak B\entails\alpha_{M,m}[z_c,c,f(c),d]\) for all
\(d\), fix some \(c_0\in B\) and put \(z\defeq z_{c_0}\).  In both cases:
every conjunct that is not a \(u\)-clause holds at \((c,f(c),d)\) for all
\(c,d\in B\); and every \(u\)-clause holds with \(u\mapsto z\) and
\(y\mapsto d\) for all \(d\in B\) (in the second case take \(x\mapsto c_0\)).
Put \(\bar n\defeq f^{n}(z)\) for \(n\in\mathbb N\).

\emph{(b) Simulation.}  For every \((i,a,b)\in\mathcal R\),
\(\mathfrak B\entails K_i[\bar a,\bar b]\).  By induction along the
computation.  Start: if \(m=0\), the \(u\)-clause \(K_0uu\) gives
\(K_0[\bar0,\bar0]\).  If \(m\geq1\), \(A_0uu\) gives \(A_0[\bar0,\bar0]\); the
clause \(A_lxy\to A_{l+1}vy\) at \(x\mapsto\bar l\), \(y\mapsto\bar0\) gives
\(A_{l+1}[\overline{l+1},\bar0]\) for \(l<m\), since \(f(\bar l)=
\overline{l+1}\); and \(A_mxy\to K_0xy\) gives \(K_0[\bar m,\bar0]\).  Step:
let \((i,a,b)\in\mathcal R\) with \(\mathfrak B\entails K_i[\bar a,\bar b]\).
\begin{itemize}
\item \(I_i=(i,1,j)\): the clause \(K_ixy\to K_jvy\) at \(x\mapsto\bar a\),
      \(y\mapsto\bar b\) gives \(K_j[\overline{a+1},\bar b]\).
\item \(I_i=(i,2,j)\): \(K_iyx\to K_jyv\) at \(x\mapsto\bar b\),
      \(y\mapsto\bar a\) gives \(K_j[\bar a,\overline{b+1}]\).
\item \(I_i=(i,1,j,k)\), \(a=a_0+1\): \(K_ivy\to K_kxy\) at \(x\mapsto
      \bar a_0\), \(y\mapsto\bar b\), where \(f(\bar a_0)=\bar a\), gives
      \(K_k[\bar a_0,\bar b]\).  If \(a=0\): the \(u\)-clause \(K_iuy\to
      K_juy\) at \(y\mapsto\bar b\) gives \(K_j[\bar0,\bar b]\).
\item \(I_i=(i,2,j,k)\): in the same way with \(K_iyv\to K_kyx\) and
      \(K_iyu\to K_jyu\).
\end{itemize}
In each case the conclusion is the atom of the next configuration.

\emph{(c) Distinct elements.}  If \(a\in\mathrm{Val}_{\mathcal R}\) and
\(c>a\), then \(\bar a\neq\bar c\).  Indeed, \(a\) occurs in some
\((i,a,b)\in\mathcal R\) or \((i,b,a)\in\mathcal R\); by (b) and the clause
\(K_ixy\to Kxv\) at \(x\mapsto\bar a\), \(y\mapsto\bar b\), or \(K_iyx\to Kxv\)
at \(x\mapsto\bar a\), \(y\mapsto\bar b\), we get
\(K[\bar a,\overline{a+1}]\).  The clause \(Kyx\to Kyv\) at \(y\mapsto\bar a\),
\(x\mapsto\bar n\) turns \(K[\bar a,\bar n]\) into \(K[\bar a,
\overline{n+1}]\); by induction, \(K[\bar a,\bar c]\) for all \(c>a\).  Since
\(\neg K[\bar c,\bar c]\) by \(\neg Kxx\), \(\bar a\neq\bar c\).  Hence the
map \(a\mapsto\bar a\) is injective on \(\mathrm{Val}_{\mathcal R}\), and
\(\lvert B\rvert\geq\lvert\mathrm{Val}_{\mathcal R}\rvert\).

\emph{(d) The intended models.}  Suppose \((1,0,0)\notin\mathcal R\).  If the
computation halts, put \(N\defeq\max\mathrm{Val}_{\mathcal R}\),
\(D\defeq\{0,\ldots,N+1\}\), and \(\sigma(c)\defeq c+1\) for \(c\leq N\),
\(\sigma(N+1)\defeq N+1\).  If it does not halt, put \(D\defeq\mathbb N\) and
\(\sigma(c)\defeq c+1\).  In both cases \(m\in\mathrm{Val}_{\mathcal R}\),
every register content is a member of \(D\) at which \(\sigma(c)=c+1\), and
\(\sigma(c)\geq c\) for all \(c\in D\).  Let \(\mathfrak D\) have domain \(D\),
\(K^{\mathfrak D}\defeq\{(a,c)\in D^{2}:a<c\}\), \(K_i^{\mathfrak D}\defeq
\{(a,b):(i,a,b)\in\mathcal R\}\) and \(A_l^{\mathfrak D}\defeq\{(l,0)\}\).
We show \(\mathfrak D\entails\alpha_{M,m}[0,c,\sigma(c),d]\) for all
\(c,d\in D\); then \(0\) witnesses \(\exists u\) and \(\sigma(c)\) witnesses
\(\exists v\) at \(c\) in both prefixes, so \(\mathfrak D\) is a model of
\(\beta\).
\begin{itemize}
\item Step clauses.  If \((i,c,d)\in\mathcal R\) and \(I_i=(i,1,j)\), the next
      configuration \((j,c+1,d)\) is in \(\mathcal R\) and \(\sigma(c)=c+1\);
      the case \((i,2,j)\) is the same.  If \(I_i=(i,1,j,k)\) and
      \((i,\sigma(c),d)\in\mathcal R\), then \(\sigma(c)\) is a register
      content; in the finite case this excludes \(c=N+1\), whose image
      \(N+1\) exceeds every register content, so \(\sigma(c)=c+1\geq1\) in
      both cases, and the next configuration
      \((k,c,d)\) is in \(\mathcal R\); if \((i,0,d)\in\mathcal R\), the next
      configuration \((j,0,d)\) is in \(\mathcal R\).  The case
      \((i,2,j,k)\) is the same.
\item \(\mathrm{START}_m\).  \((0,m,0)\in\mathcal R\).  For \(m\geq1\),
      \(A_0(0,0)\) holds; if \(A_l(c,d)\) with \(l<m\), then \(c=l<m\leq N\),
      \(d=0\) and \(A_{l+1}(\sigma(l),0)=A_{l+1}(l+1,0)\) holds; if
      \(A_m(c,d)\), then \((c,d)=(m,0)\) and \(K_0(m,0)\) holds.
\item \(\mathrm{NOSTOP}\): \((1,0,0)\notin\mathcal R\).
\item \(\prec_{K,M}\).  \(K^{\mathfrak D}\) is irreflexive.  If \(d<c\), then
      \(d<\sigma(c)\).  If \((i,c,d)\in\mathcal R\) or \((i,d,c)\in
      \mathcal R\), then \(c\) is a register content and \(c<c+1=\sigma(c)\).
\end{itemize}
If the computation halts, \(\mathfrak D\) has \(N+2\) elements.

\emph{(e) Conclusion.}  By hypothesis, a halting computation ends in
\((1,0,0)\) or \((2,0,0)\), and these are exclusive.  If
\((1,0,0)\in\mathcal R\), then by (b) every model satisfies
\(K_1[\bar0,\bar0]=K_1[z,z]\), against the \(u\)-clause \(\neg K_1uu\); so
\(\beta\) is contradictory.  If the computation ends in \((2,0,0)\), (d)
gives a model with \(N+2\) elements.  If it never halts, (d) gives a model;
by hypothesis \(\mathrm{Val}_{\mathcal R}\) is infinite, so by (c) every model
is infinite, and \(\beta\) is an infinity axiom.  The three cases are
exhaustive and exclusive, and so are the three conclusions, which gives the
three equivalences.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-ex-2-1-32}{thm:p02-w02b-p02-031-ex-2-1-32}{Trakhtenbrot's theorem with register-machine formulas}
\begin{proof}
For \(e\in V\), the table of \(M_e\) is decoded from \(e\), so \(e\mapsto
M^{0}_{M_e}\) and \(e\mapsto\psi_e\) are computable on \(V\).  By
\cref{thm:p02-w02b-p02-031-two-register-simulation}, applied to \(M_e\) and the
empty word, the computation of \(M^{0}_{M_e}\) from \((0,0,0)\) meets the
hypotheses of \cref{thm:p02-w02b-p02-031-register-reduction} with \(m=0\).
If \(e\in H_1\), it reaches \((1,0,0)\) by property~1, so \(\psi_e\) is
contradictory.  If \(e\in H_2\), it reaches \((2,0,0)\) by property~2, so
\(\psi_e\) is finitely satisfiable.  If \(e\in H_\infty\), it never halts by
property~4, so \(\psi_e\) is an infinity axiom.  Since \(H_1,H_2,H_\infty\)
partition \(V\) and the three classes are disjoint, the three implications
are equivalences.

Let \(Y\) be a recursive class containing every \(\psi_e\).  Pair
\(\mathrm{Non\text{-}sat}(Y)\) with \(H_1\), \(\mathrm{Fin\text{-}sat}(Y)\)
with \(H_2\) and \(\mathrm{Inf\text{-}axioms}(Y)\) with \(H_\infty\).  Let
\(\mathcal C\neq\mathcal C'\) be two of the classes, with halting sets
\(H\) and \(H'\), and suppose a decidable \(W\) separates \(\mathcal C\) from
\(\mathcal C'\).  Then \(W'\defeq\{e\in V:\psi_e\in W\}\) is decidable,
contains \(H\) and is disjoint from \(H'\), against
Lemma~\ref{thm:p02-w02-p02-036-halting}.  The class
\([\exists\forall\exists\forall]\cap\mathrm{KROM}\cap\mathrm{HORN}\) with only
binary predicate symbols is recursive, because membership is read off the
syntax, and it contains every \(\psi_e\) by the remark after
Definition~\ref{def:p02-w02b-p02-031-register-formulas}.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-logic-machine}{thm:p02-w02b-p02-031-logic-machine}{A logic machine for unsatisfiability and finite satisfiability}
\begin{proof}
By \cref{thm:p02-w02b-p02-031-eff-classes}, \(\mathrm{Fin\text{-}sat}\) and
\(\mathrm{Non\text{-}sat}\) are computably enumerable, and they are disjoint.
By \cref{thm:p02-w02b-p02-031-code-constructions}(1) there are \(i_F,i_N\)
with \(W_{i_F}=\mathrm{Fin\text{-}sat}\) and \(W_{i_N}=\mathrm{Non\text{-}sat}\).
Let \(\mathcal T_L\defeq M_{d(i_F,i_N)}\), with \(d\) as in
\cref{thm:p02-w02b-p02-031-code-constructions}(3).  Its input alphabet
contains the digits, since \(d(i_F,i_N)\) is a valid code.  For a formula
\(\psi\) with code \(n=\ulcorner\psi\urcorner\): if \(\psi\in
\mathrm{Fin\text{-}sat}\), then \(n\in W_{i_F}\setminus W_{i_N}\) and
\(\mathcal T_L\) accepts \(\operatorname{bin}(n)\); if \(\psi\in
\mathrm{Non\text{-}sat}\), it rejects \(\operatorname{bin}(n)\); if \(\psi\in
\mathrm{Inf\text{-}axioms}\), then \(n\notin W_{i_F}\cup W_{i_N}\) and it never
halts, by the last clause of item~3.  Put \(M_L\defeq M_{\mathcal T_L}\) and
\(m(\psi)\defeq m_{\mathcal T_L}(\operatorname{bin}(\ulcorner\psi\urcorner))\),
as in \cref{thm:p02-w02b-p02-031-two-register-simulation}; \(m\) is computable.
Properties 1--4 of that theorem give the three cases and the form of the stop
configurations.  Since the three classes partition \(\mathrm{FO}\) and a
computation reaches at most one stop configuration,
\(H'_{M_L,1}=\mathrm{Non\text{-}sat}\) and \(H'_{M_L,2}=
\mathrm{Fin\text{-}sat}\).
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-ex-2-1-34}{thm:p02-w02b-p02-031-ex-2-1-34}{The refined logic-machine formulas reduce both problems at once}
\begin{proof}
Let \(\psi\in\mathrm{FO}\).  By \cref{thm:p02-w02b-p02-031-logic-machine}, the
computation of \(M_L\) from \((0,m(\psi),0)\) meets the hypotheses of
\cref{thm:p02-w02b-p02-031-register-reduction}: its stop configurations are
\((1,0,0)\) or \((2,0,0)\), and it has unbounded register contents when it
does not halt.  If \(\psi\in\mathrm{Non\text{-}sat}\), it reaches \((1,0,0)\)
and \(g(\psi)\) is contradictory by item~1 of that theorem.  If \(\psi\in
\mathrm{Fin\text{-}sat}\), it reaches \((2,0,0)\) and \(g(\psi)\) is finitely
satisfiable by item~2.  If \(\psi\in\mathrm{Inf\text{-}axioms}\), it never
halts and \(g(\psi)\) is an infinity axiom by item~3.  This is item~3 of the
corollary.  A formula is satisfiable iff it lies in \(\mathrm{Fin\text{-}sat}\)
or \(\mathrm{Inf\text{-}axioms}\), and these three classes are disjoint, so
items 1 and~2 follow.  The map \(g\) is computable: \(\psi\mapsto m(\psi)\)
is computable, and \(\beta_{M_L,\prec,m}\) is written down from the fixed
table of \(M_L\) and the number \(m\) by
Definition~\ref{def:p02-w02b-p02-031-register-formulas}.  The Skolem normal
form is the one described after that definition.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p02-w02b-p02-031-ex-2-1-37}{thm:p02-w02b-p02-031-ex-2-1-37}{Two conservative reduction classes of Krom and Horn sentences}
\begin{proof}
Let \(X_1\) and \(X_2\) be the two classes.  Both are recursive, since
membership is decided by inspecting the prefix, the clauses of the matrix and
the arities of the predicate symbols; and \(\mathrm{FO}\) is recursive.  By
the remark after Definition~\ref{def:p02-w02b-p02-031-register-formulas},
\(g(\psi)\in X_1\) and \(g^{+}(\psi)\in X_2\) for every \(\psi\).  The map
\(g\) is a conservative reduction from \(\mathrm{FO}\) to \(X_1\) by
\cref{thm:p02-w02b-p02-031-ex-2-1-34}(1)--(2).  For \(g^{+}\), repeat the
proof of \cref{thm:p02-w02b-p02-031-ex-2-1-34} with
\(\beta^{+}_{M_L,\prec,m(\psi)}\) in place of \(\beta_{M_L,\prec,m(\psi)}\):
\cref{thm:p02-w02b-p02-031-register-reduction} is stated for both, so the three
cases give that \(g^{+}(\psi)\) is contradictory, finitely satisfiable or an
infinity axiom according as \(\psi\) is; \(g^{+}\) is computable for the same
reason as \(g\).  So both clauses of
Definition~\ref{def:p02-w02-p02-036-conservative} hold for \(g^{+}\).
\end{proof}
\end{annexitem}
