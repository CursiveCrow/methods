\begin{annexitem}{annex:p2.hol.5}{thm:p02-many-sorted-translation}{Reduction of strict many-sorted consequence to one-sorted consequence}
\begin{proof}
First assume the one-sorted consequence fails under an assignment \(s\).  Let
\(\mathcal A\) satisfy \(\mathsf{Ax}_{\mathrm{sort}}(\Lang_{\mathrm{MS}})\),
\(\mathsf{VarGuard}_{\mathrm{MS}}(\Lang_{\mathrm{MS}})\), and every member of
\(\operatorname{tr}_{\mathrm{MS}}[\Gamma]\), but not
\(\operatorname{tr}_{\mathrm{MS}}(\varphi)\).  Put
\(M_{\mathsf s}\defeq Q_{\mathsf s}^{\mathcal A}\).  Nonemptiness and pairwise-disjointness
follow from the first and fourth axiom families; constant typing and function
closure make the restrictions of the old symbols well typed.  Restrict each
relation to the matching product of the \(M_{\mathsf s}\)'s.  Induction on terms, then
on well-sorted formulas, gives, for every matching assignment \(s\),
\[
 \mathcal M,s\entails\psi
 \quad\Longleftrightarrow\quad
 \mathcal A,s\entails\operatorname{tr}_{\mathrm{MS}}(\psi).
\]
The atomic cases use the restrictions and same-sort equality; the guarded
quantifier clauses use exactly
\(M_{\mathsf s}=Q_{\mathsf s}^{\mathcal A}\).  The all-variable assignment
guard makes the given \(s\) a total matching sorted assignment, with no choice
of default values.  Thus the restricted many-sorted \(\mathcal M\) satisfies
\(\Gamma\) and refutes \(\varphi\).

Conversely, let a strict many-sorted \(\mathcal M,s\) satisfy \(\Gamma\) and
refute \(\varphi\).  Take the one-sorted domain to be the tagged union
\(\bigcup_{\mathsf s}\{\mathsf s\}\times M_{\mathsf s}\) together with one
fresh untyped point \(\star\), interpret
\(Q_{\mathsf s}\) by its \(\mathsf s\)-tagged
component, tag the assignment, and transport constants and correctly typed
function values.  Send every ill-typed positive-arity function input to
\(\star\), a simultaneous choice-free extension.
Interpret each relation by the transported correctly typed tuples and make it
false elsewhere.  The four sort-axiom families hold.  The same induction gives
truth preservation, so the resulting one-sorted structure satisfies the
translated premises and refutes the translated conclusion.  Taking
contrapositives in both directions proves the stated equivalence.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p2.hol.7}{thm:p02-sol-incidence-satisfaction}{Incidence translation preserves satisfaction}
\begin{proof}
Tag \(s\) to \(s^\sharp\).  Structural induction begins with
\[
 \mathcal H,s\entails X^n(\bar t)
 \quad\Longleftrightarrow\quad
 \lbrack\!\lbrack\bar t\rbrack\!\rbrack_s^{\mathcal H}\in s(X^n)
 \quad\Longleftrightarrow\quad
 \mathcal H^\sharp,s^\sharp\entails E_n(X^n,\bar t).
\]
For a predicate constant, the middle relation is
\(P^{\mathcal H}\), represented by
\(\widehat P^{\mathcal H^\sharp}=(S_n,P^{\mathcal H})\), so its incidence
atom has the same truth value; the theorem's predicate-closure hypothesis puts
that value in \(S_n^{\mathcal H^\sharp}\).  Object terms use their tags; Booleans are
immediate.  Object and relation quantifiers use the bijections
\(a\mapsto(D,a)\) and \(R\mapsto(S_n,R)\).  Applying the equivalence to every
eligible universally closed \(\chi\)-instance gives exactly its translated
member of \(T_{\mathsf{CC}}^\sharp\), with unchanged eligibility and parameter
sorts, proving the schema equivalence.  Every case of this induction, with
the term clause and the assignment correspondence it uses, is written out in
the proof of \cref{thm:p02-w02-p02-041-tagging}.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p2.hol.8}{thm:p02-sol-derived-adequacy}{Strong adequacy of the matched relational calculus}
\begin{proof}
Suppose
\(\Gamma\derives_{\mathsf{SOL}_{\mathrm H}^{\mathsf{CC}}}\varphi\).
By definition,
\(T_{\mathsf{CC}}^\sharp\cup\Gamma^\sharp
\derives_{\mathsf{MSFOL}}\varphi^\sharp\).  Soundness of
\(\mathsf{MSFOL}\), followed by
Theorem~\ref{thm:p02-sol-incidence-satisfaction}, shows that every
\(\mathsf H_{\mathsf{CC}}\)-model of \(\Gamma\) satisfies \(\varphi\).

Conversely, if the translated derivation does not exist, guarded strong
completeness of \(\mathsf{MSFOL}\) gives a strict many-sorted model
\(\mathcal A\) and sorted assignment \(s\) satisfying
\(T_{\mathsf{CC}}^\sharp\cup\Gamma^\sharp\) and refuting
\(\varphi^\sharp\).  For each \(r\in S_n^{\mathcal A}\), let
\[
 \operatorname{ext}_n(r)\defeq
 \{\bar a\in(D^{\mathcal A})^n:
   \mathcal A\entails E_n(r,\bar a)\},
 \qquad
 \mathcal R_n\defeq
 \{\operatorname{ext}_n(r):r\in S_n^{\mathcal A}\}.
\]
Use \(D^{\mathcal A}\) as object domain, retain every object constant and
function from \(\mathcal A\), and interpret each predicate constant by
\(\operatorname{ext}_n(\widehat P^{\mathcal A})\).  Put
\(s^{\mathrm{ext}}(x)=s(x)\) and
\(s^{\mathrm{ext}}(X^n)=\operatorname{ext}_n(s(X^n))\).  By
\cref{thm:p02-w02-p02-041-collapse}(c), whose annex proof writes out every
case of the induction on source formulas, truth is preserved.  Possible
duplicate values with the same extension are
invisible because the source language has neither relation equality nor any
operation on relation-sort objects besides incidence.  Thus this extensional
collapse is an \(\mathsf H_{\mathsf{CC}}\)-model of \(\Gamma\) refuting
\(\varphi\).  Given a collapsed assignment to the finitely many relation
parameters of a schema instance, choose one representative in \(\mathcal A\)
for each value; finite choice needs no choice axiom.  The universally quantified
translated schema supplies a witness, whose extension supplies the collapsed
comprehension relation or choice graph.  Hence every matched schema survives.
This
contradicts \(\Gamma\entails_{\mathrm H}^{\mathsf{CC}}\varphi\), proving
completeness.

Finally, \(\forall^2L\) and \(\exists^2R\) translate to sorted
instantiation.  For \(\forall^2R\) and \(\exists^2L\), isolate and discharge
the eigenvariable's assignment-guard premise before generalization; freshness
excludes that variable from every remaining premise, and weakening then
restores the global guard set.
Classical disjunction handles the two-sided contexts.  Each Comp or Choice
conclusion translates to an axiom of \(T_{\mathsf{CC}}^\sharp\); hence all
six displayed additions are admissible for the exact sheet projection.
\end{proof}
\end{annexitem}
