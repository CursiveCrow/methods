\begin{annexitem}{annex:p15-flt-informant-channels}{thm:p15-flt-informant-channels}{Channel simulation without a time-bound claim}
\begin{proof}
An algorithm for all fair informants works on the particular
methodical presentation. A methodical algorithm can be used
with a request informant by querying the fixed enumeration
\(b(0),b(1),\ldots\).
Conversely simulate a request learner from arbitrary fair data.
Cache every observed word/label pair. Maintain its virtual
transcript and its next requested word. At each real observation
advance at most one virtual request if its answer is cached;
otherwise retain the previous output, or initially abstain.
The finite computations of the request strategy terminate
by its effectiveness assumption, so this prefix simulator
is total. Each pending request is eventually answered because
the real informant is fair and truthful.
Induction shows that every virtual stage is eventually reached.
After the virtual learner stabilizes, only that same hypothesis
is repeated in the real simulation. Delays are finite but need
not have a computable uniform bound.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p15-flt-enumeration}{thm:p15-flt-enumeration}{Least consistency and its actual totality premise}
\begin{proof}
For finite data, testing a candidate involves finitely many
calls to the total joint \(D\); testing all \(e\leq n\)
therefore terminates. Let \(i\) be the least index with
\(H_i=L\). It is never contradicted by truthful data.
For each \(j<i\), choose a word whose membership in
\(H_j\) differs from its membership in \(L\).
Fairness presents that word and its true label at a finite
stage; from then on \(j\) remains inconsistent.
There are only finitely many such smaller indices.
Once all witnesses have appeared and \(n\geq i\),
the learner chooses exactly \(i\) forever.
Hard-coding \(i\) into the fixed program for \(D\) yields
its tester code effectively; a fixed compiler preserves
stabilization when Gold program names, rather than family
parameters, are required.

For the primitive-recursive instance, finite well-typed
descriptions use the initial functions, composition and
primitive recursion with explicit arities.
Syntax and arity checks are decidable. Enumerate all valid
unary descriptions. Evaluation terminates by structural
induction: composition calls finitely many smaller terms,
and a recursion node performs the input's finite number
of iterations on its smaller body term.
This yields a total recursive joint interpreter \(p(e,n)\).
Composing with the Boolean map \(w(z)=1\) iff \(z=1\)
gives a joint decider for exactly the primitive-recursive
characteristic-function family; every such characteristic
function has a description and is unchanged by \(w\).
The interpreter is not asserted primitive recursive.
The effective word/integer coding transports this argument
to \(\mathcal W\). No enumeration of every total recursive
program has been used.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p15-flt-finite-text}{thm:p15-flt-finite-text}{Finite content and stable compiled names}
\begin{proof}
On a finite prefix compute the finite nonpause content,
convert its words to indices, and add their distinct
powers of two. The membership procedure for parameter
\(d\) returns the corresponding bit at the input word's
index. This is a total effective tester uniformly in \(d\).
Its finite program template with hard-coded \(d\) gives
a deterministic effective compiler \(c(d)\).

For a finite target \(F\), each of its finitely many words
has a first occurrence. After the largest of those finitely
many stages, content is exactly \(F\).
No word outside \(F\) occurs, so the parameter and compiled
tester stay fixed forever and name \(F\).
For the empty-language pause presentation, content always
remains empty and the code is \(c(0)\).
For a pure positive text of a nonempty finite target the
same proof uses no pauses at all.
In the worked unary trace, index two contributes \(2^2=4\),
and the later empty word contributes \(2^0=1\); repetitions
and pauses contribute nothing new. This gives the displayed
parameters \(0,4,4,5,5,5\).
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p15-flt-pr-text}{thm:p15-flt-pr-text}{Learning the presentation program and the nonempty range condition}
\begin{proof}
Effectively enumerate the unary primitive-recursive numerical
functions by their finite descriptions, using the total
joint interpreter just constructed. Through the fixed word
coding they give primitive-recursive word sequences.
At prefix length \(n\), choose the least \(e\leq n\) whose
sequence agrees with every observed position, or abstain.
This finite search terminates. For a primitive-recursive
text there is a least index for that entire sequence.
Each smaller distinct sequence disagrees at some finite
position, eventually observed. Hence the chosen program
index stabilizes, just as in the informant enumeration proof.
Compile its sequence program as a generator. Its range is
exactly the text's range \(L\), so the final name is correct.
This construction does not decide membership in that range.

For existence of a primitive-recursive text of any nonempty
r.e. \(L\), use a primitive-recursive accepted-computation
witness predicate \(Q(i,s)\) for the r.e. set of indices
\(\{i:b(i)\in L\}\). Such a predicate is supplied by the
normal-form/computation coding in
\cref{thm:p04-kleene-normal-form}.
Choose one fixed \(a\in L\).
On the effective numerical code of pair \((i,s)\),
output \(b(i)\) if \(Q(i,s)\), and otherwise output \(a\).
Bounded pairing projections and the fixed word coding
are primitive recursive, so this is a primitive-recursive
sequence. Every output belongs to \(L\), and every word
in \(L\) occurs for some accepting witness.
The fixed \(a\) is legitimate because \(L\ne\varnothing\);
no total procedure for deciding emptiness or finding \(a\)
from every r.e. index is asserted.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p15-flt-superfinite}{thm:p15-flt-superfinite}{Arbitrary-text and effective recursive-text diagonals}
\begin{proof}
First allow an arbitrary, possibly noneffective learner
and assume it identifies every finite language and some
infinite \(L\) on every text.
Fix a repetition-free enumeration \(a_1,a_2,\ldots\) of
\(L\), without an effectivity claim in this first argument.
Construct prefixes \(u_r\) inductively.
Append \(a_r\) to the preceding prefix; its finite content
is \(F_r=\{a_1,\ldots,a_r\}\).
Complete this prefix to a text of \(F_r\), using only
words of \(F_r\). By assumed finite-language identification,
there is a finite extension at which the guessed code
actually names \(F_r\). Retain that extension as \(u_r\)
and proceed to the next fresh word.

The increasing union is a text for \(L\): no other word
was inserted and each \(a_r\) occurs.
At infinitely many increasing stages its hypothesis names
the finite \(F_r\), not \(L\), so it is not eventually
semantically correct and cannot identify \(L\).
Choosing those semantic stages is an existence argument,
not a claimed algorithm for testing language equality.
All \(F_r\) are nonempty, so the contradiction already
holds in Gold's pure-text convention.

Now reconstruct Gold's effective version. If an infinite
target has no generator name, identification is already
impossible; otherwise its r.e. words can be enumerated
recursively without repetition. Simulate an enumeration
and wait for the next previously unseen output; each
such wait terminates because the language is infinite.
Let the resulting sequence again be \(a_1,a_2,\ldots\).

At stage \(r\), the current prefix \(u\) has included
exactly the first \(2r-2\) distinct words.
Search all positive pairs \(x,y\), in increasing finite
diagonal order, for
\[
 G(u a_{2r-1}^{\,x})
 \ne G(u a_{2r-1}^{\,x}a_{2r}^{\,y}).
\]
This test involves only computing two finite outputs and
comparing their codes; it is decidable.
The search succeeds. Indeed, the recursive continuation
\(u a_{2r-1}^{\omega}\) is a text of the finite
first \(2r-1\) words. For some sufficiently large \(x\)
the learner guesses its correct final generator name.
The continuation
\(u a_{2r-1}^{\,x}a_{2r}^{\omega}\) is a text of the
different finite first \(2r\) words. At a sufficiently
large \(y\) its correct name differs from the first.
Different languages cannot have one identical correct
program name. Existence of this pair, not recognition
of its semantic correctness, proves search termination.

Append the two found blocks and repeat.
Their lengths are positive, so every \(a_j\) occurs
and the resulting text has range exactly \(L\).
Every stage forces a change between two increasing
prefix lengths. Thus the output sequence changes
infinitely often and fails syntactic stabilization.
To compute any requested text position, construct
successive finite stages until reaching that position;
every search terminates and lengths strictly increase.
Hence the countertext is recursive.
There is no primitive-recursive time bound for those
unbounded searches in this proof.
This establishes precisely the stronger recursive-text
generator obstruction without a universal tester or
semantic-equality oracle.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p15-flt-no-uniform-list}{thm:p15-flt-no-uniform-list}{Two direct enumeration diagonals}
\begin{proof}
If a total joint \(D\) listed every recursive language,
define \(L^\dagger=\{b(e):D(e,b(e))=0\}\).
To decide membership of \(w\), compute \(e=b^{-1}(w)\)
and negate \(D(e,w)\); hence \(L^\dagger\) is recursive.
At \(b(e)\) it differs from the \(e\)-th listed language
for every \(e\), a contradiction.

If a total recursive \(p(e,n)\) listed every total
recursive numerical function, the total recursive
function \(f(n)=p(n,n)+1\) would differ from the
\(n\)-th member at input \(n\), again a contradiction.
Duplicates in a purported list do not affect either
diagonal. These facts do not preclude a total recursive
interpreter for all primitive-recursive descriptions:
the diagonal then escapes that smaller class.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p15-flt-all-recursive}{thm:p15-flt-all-recursive}{The native zero/one block informant diagonal}
\begin{proof}
For a finite bit string \(u\), write \(G(u)\) for the
learner applied to the methodical word/label pairs
\((b(j),u(j))\); this is an effective finite encoding,
not a positive text.
Assume \(G\) identifies every finite and cofinite
language on such informants.
From the current prefix \(u\), search positive \(x,y\)
with \(G(u0^x)\ne G(u0^x1^y)\).
For each pair two computations terminate and code
inequality is decidable.

For existence of a successful pair, the completion
\(u0^\omega\) is the characteristic sequence of a
finite language. At some large \(x\) the guess is its
correct stabilized name.
The completion \(u0^x1^\omega\) is the characteristic
sequence of a cofinite, hence different, language.
At some sufficiently large \(y\) its name differs.
Thus the search terminates.
Append the two blocks and iterate.
To compute a bit at position \(n\), construct enough
finite stages to reach \(n\); their lengths increase
and every stage terminates.
The infinite sequence is therefore recursive, so its
ones form a recursive language. But the hypotheses
change between the two ends of every stage, infinitely
often. The learner fails on this recursive target.
This proof uses no membership test for the guessed
generator languages.

A tester can be compiled to a generator by scanning
the fixed word list and emitting each accepted word.
This is an effective program transformation.
A stabilized correct tester code therefore yields a
stabilized correct generator code. Consequently a
tester learner for all recursive languages would
contradict the just-proved generator obstruction.
The generator's stream/partial enumeration does not
supply a terminating negative membership answer.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p15-flt-no-certificate}{thm:p15-flt-no-certificate}{Delayed positive evidence defeats an announced stop}
\begin{proof}
Suppose such a procedure always halts with a correct
target name on every text of every finite language.
Choose a nonempty finite \(F\) and one of its texts.
At its halting stage only a finite prefix \(\sigma\)
has been observed.
Choose \(z\notin F\), possible because the nonempty
alphabet gives infinitely many finite words.
The same \(\sigma\) begins a text for \(F\cup\{z\}\):
after it present the remaining words and \(z\), then
repeat the finite set. The procedure halts at the
same prefix with the same answer, which cannot name
both different languages.
This contradicts its guarantee. It does not contradict
the finite-language limit learner, which keeps receiving
data and does not announce that its present guess is final.
\end{proof}
\end{annexitem}
