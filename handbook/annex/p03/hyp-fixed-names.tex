\begin{annexitem}{annex:p3.adm.15}{thm:p03-adm-constructible-recursion}{Constructible recursion}
\begin{proof}
For a proper set \(X\), its finite tuples and the first-order
satisfaction relation of \((X,\in)\) are available by
\cref{thm:p03-adm-satisfaction}: collect the unique evaluations of
all finite formula codes by functional \(\Sigma\)-Replacement on
the set of those codes, and unite their assignment records. No single
infinitary formula with infinitely many free variables is required.
Enumerate formula indices and finite
parameter tuples from \(X\). Each index and tuple determines a subset
of \(X\) by bounded Separation using that satisfaction relation.
Functional \(\Sigma\)-Replacement collects their values. The range
is exactly \(\operatorname{Def}(X)\). This construction uses neither
a power set of \(X\) nor satisfaction for the ambient universe.
Its graph is \(\Sigma_1\) and provably functional, with the
satisfaction and collection records as certificates.

Start with \(L_0=\varnothing\), take
\(L_{\gamma+1}=\operatorname{Def}(L_\gamma)\), and take unions at
limits. \Cref{thm:p03-adm-membership-recursion} performs this recursion
on each ordinal. At each successor retain the earlier well-order first,
then order the new sets by their least definition codes. A code records
a formula index and a finite parameter tuple; order these first by
length and formula index and then lexicographically in the already
constructed well-order for that fixed length. This is a well-order.
Each new set has a least code. At limits take the union of the earlier
orders. The earlier levels are initial segments of every later order.
All comparisons and least-code tests are bounded by the set of codes
and its well-order, so the paired hierarchy-and-order recursion is
again \(\Sigma_1\) and functional. Induction proves compatibility of
any two construction records on their common initial interval. These
are proofs inside KPU. The construction starts with the empty set and
never introduces an urelement.

Now let \(B\) be transitive admissible of height \(\beta\), with
\(\omega\in B\). Internal recursion agrees with the actual recursion
by transitivity and uniqueness. Thus \(L_\gamma\in B\) for every
\(\gamma<\beta\), and \(L_\beta\subseteq B\). The height is a
limit ordinal, since every ordinal in \(B\) has its successor in
\(B\). The elementary closures of \(L_\beta\) give Empty Set,
Pairing, Union, and bounded Separation: put the finitely many parameters
in a sufficiently large transitive level, and form the required
subset there at the next level. Foundation holds by external
well-foundedness. Moreover \(\beta>\omega\), and the finite-set
construction followed by its next definability level places
\(\omega\) in \(L_\beta\).

For Collection suppose, in \(L_\beta\),
\(\forall x\in a\,\exists y\,\theta(x,y,p)\), with \(\theta\)
bounded. For every \(x\in a\), the structure \(B\) then satisfies
that there are \(\gamma\), a construction record for \(L_\gamma\),
and \(y\in L_\gamma\) with \(\theta(x,y,p)\). This is a
\(\Sigma_1\) condition, using bounded absoluteness.
\(\Sigma\)-Collection in \(B\) collects these packages. Their
ordinal components have a common ordinal bound \(\eta<\beta\),
chosen larger than each component. The set \(L_\eta\), which belongs
to \(L_\beta\), therefore collects the required witnesses. This
proves bounded Collection, hence admissibility of \(L_\beta\).
The argument never requires that every member of \(B\) be pure.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p3.adm.16}{thm:p03-hyp-least}{Existence and leastness}
\begin{proof}
Work in the surrounding set theory with Choice, as in
\cref{thm:p03-w03-p03-039-nadel-hkappa}. That theorem supplies the
transitive admissible set \(H(\omega_1)\), containing \(\omega\).
The preceding lemma supplies a constructible level with the same
properties. There is consequently a least ordinal \(\alpha\)
whose level is admissible and contains \(\omega\).
If \(B\) is any transitive admissible set containing \(\omega\),
its constructible inner level \(L_\beta\) has these properties, so
\(\alpha\leq\beta\) and \(L_\alpha\subseteq L_\beta\subseteq B\).
This proves leastness and the assertion about urelements.

For countability, start inside \(H(\omega_1)\) with the countable
collection consisting of \(\omega\) and all its elements. Repeatedly
adjoin one witness for each first-order existential formula with
parameters already chosen whenever a witness exists in
\(H(\omega_1)\). There are only countably many such requirements
at each stage. The union over \(\omega\) stages is countable and
elementary by the existential-witness criterion. Its membership
relation is externally well founded. It is extensional because
witnesses to differences of two sets belong to the elementary
substructure. Recursive collapse along membership therefore maps it
isomorphically onto a transitive set \(B\). The collapse fixes every
natural number and \(\omega\). Elementarity makes \(B\)
admissible, and it remains countable. By leastness
\(L_\alpha\subseteq B\), so \(L_\alpha\) is countable.
\end{proof}
\end{annexitem}

\begin{annexitem}{annex:p3.adm.17}{thm:p03-hyp-fixed-names}{The naming hull}
\begin{proof}
Put \(A=L_\alpha=\mathrm{HYP}\). We first specify partial functions
whose graphs have unique \(\Sigma_1\) definitions provably in KPU.
For each bounded formula \(\theta(y,\bar p)\), choose the least pure
constructible witness in the canonical order, when one exists. Its
graph asserts the existence of a constructed level \(L_\gamma\) and
its canonical order, an element \(y\) of that level satisfying
\(\theta\), and the failure of \(\theta\) at each earlier element
of that level. The last test is bounded by the level. Construction
certificates are \(\Sigma_1\), so the whole assertion is
\(\Sigma_1\). Coherence and the initial-segment property of the
canonical orders prove uniqueness, also in models not satisfying
\(V=L\). In \(A\), every existing witness is constructible, so the
function is defined whenever \(\exists y\,\theta\) is true.
Finite tuples of witnesses allow the same treatment of every
\(\Sigma_1\) existential assertion.

Let \(H\subseteq A\) be the closure of \(\omega\cup\{\omega\}\)
under these partial functions. This is an external closure under
finite compositions. Every member has a \(\Sigma_1\) definition
obtained by a finite term in these functions. The natural numbers have
unique bounded finite-set definitions. The set \(\omega\) has a
unique bounded description as a nonzero limit ordinal all of whose
nonzero members are successors. Hence those finite terms give
parameter-free \(\Sigma_1\) definitions, with uniqueness provable
in KPU with Infinity. It remains to prove \(H=A\).

Bounded witness closure gives \(H\prec_{\Delta_0}A\), by induction
on bounded formulas. The specified functions then give
\(H\prec_{\Sigma_1}A\).
It also gives finite-tuple closure and closure under all the uniquely
\(\Sigma_1\) specified constructions already proved, including
constructible levels and satisfaction for proper set structures.
Extensionality in \(H\) follows by taking a witness in the symmetric
difference of two different sets. Collapse its well-founded membership
relation to a transitive structure \(B\), and write \(\pi:H\to B\)
for the collapse.

We verify the needed condensation rather than assuming admissibility
of the possibly nontransitive hull. For each ordinal \(\delta\in H\),
\[
 \pi(L_\delta)=L_{\pi(\delta)}.
\]
Induct on the ordinal \(\pi(\delta)\). The zero case is immediate.
At a successor, definitions of subsets of the preceding level use
standard finite formula indices and finite parameter tuples. All
natural numbers are in \(H\), and tuple formation and coordinate
projection preserve \(H\). The satisfaction certificate for the
preceding proper level belongs to \(H\). Its collapsed certificate
obeys the same compositional clauses: the assignment domain collapses
to all finite tuples from the collapsed level, by tuple closure;
bounded elementarity preserves the clauses. External induction on
finite formulas identifies this certificate with actual satisfaction
on that level. Consequently every definable subset supplied in the
collapsed successor is an actual definable subset of the collapsed
preceding level. Conversely, each formula and tuple from that level
lifts to a formula and tuple in \(H\); the uniquely defined subset
belongs to \(H\) by closure and collapses to the desired subset.
This proves equality at successors. At a limit, if \(x\in H\cap
L_\delta\), a lower level containing \(x\) is a \(\Sigma_1\)
witness and can be chosen with its ordinal in \(H\). Taking unions
therefore proves the limit case.

Every \(x\in H\) lies in some \(L_\delta\) with \(\delta\in H\),
again by \(\Sigma_1\) witness closure. The collapsed ordinals form an
initial segment \(\beta\leq\alpha\). The displayed equalities and
the preceding coverage show \(B=L_\beta\). The inverse collapse
\(j:L_\beta\to L_\alpha\) is \(\Sigma_1\)-elementary and preserves
the level and proper-set satisfaction constructions wherever they
occur in its domain.

Suppose \(j\) is not the identity. It must move an ordinal: if all
ordinals were fixed, induction through the levels, using the unique
subset defined by each formula and finite tuple of already fixed
parameters, would fix every constructible set in the domain. Let
\(\delta\) be its least moved ordinal. It exceeds \(\omega\).
The same induction shows that \(j\) fixes \(L_\delta\) pointwise,
while \(j(L_\delta)=L_{j(\delta)}\) and \(j(\delta)>\delta\).
The satisfaction relation of \(L_\delta\) belongs to the domain:
it is the collapse of the corresponding proper-level satisfaction
relation in \(H\). Its image is the satisfaction relation of
\(L_{j(\delta)}\). Since formula indices and parameters in
\(L_\delta\) are fixed, this implies
\(L_\delta\prec L_{j(\delta)}\).

Here is why this contradicts leastness of \(\alpha\). More generally,
if \(\omega<\delta<\gamma\) and
\(L_\delta\prec_{\Sigma_1}L_\gamma\), then \(L_\delta\) is
admissible. Pairing, Union, and bounded Separation have witnesses in
\(L_{\delta+1}\): the required subsets are definable over
\(L_\delta\). Their \(\Sigma_1\) existence assertions reflect
to \(L_\delta\). For bounded Collection, if its antecedent is true
in \(L_\delta\), the set \(L_\delta\) itself, an element of
\(L_{\delta+1}\subseteq L_\gamma\), collects all its witnesses.
Bounded absoluteness and \(\Sigma_1\) elementarity reflect a
collecting set into \(L_\delta\). Foundation follows from
transitivity, and \(\omega\in L_\delta\). This proves the claim.
Applied to the critical ordinal, it gives an admissible level
\(L_\delta\) containing \(\omega\), with
\(\delta<\beta\leq\alpha\), a contradiction.

Thus \(j\) is the identity and \(H=L_\beta\) is transitive.
A transitive \(\Sigma_1\)-elementary substructure of an admissible
set is admissible: for bounded Collection its antecedent transfers
upward, since all elements of its parameter set remain in the
substructure; a collecting set then transfers downward as a
\(\Sigma_1\) witness. The other elementary closures transfer in
the same way, and Foundation is inherited. Since \(\omega\in H\),
leastness forces \(\beta=\alpha\). Hence \(H=A\), proving the
claimed supply of finite-term names.

Finally a \(\Sigma_1\) witness in \(A\) remains a witness in a KPU
end extension: bounded formulas about old objects are absolute, because
no old set gains members. The formula \(\sigma_a\) therefore still
holds of \(a\). Its provable uniqueness in KPU excludes every other
object, including an externally ill-founded one. This proves the
stated fixed-name property.
\end{proof}
\end{annexitem}
