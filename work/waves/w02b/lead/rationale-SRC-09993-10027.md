## SRC-09993-10027

The audit table in section "A final audit table" (\label{sec:second-incompleteness-05}) is a longtable that had only a single repeated head (`\endhead`) with no caption, no distinct first head, and no continuation foot, so a reader reaching a page break had no signal that the table continued and the continued page carried no identifying caption. The corrected head now gives the table the caption "A final audit table" on its first page (`\endfirsthead`), repeats the head rows verbatim under the caption "A final audit table (continued)" on later pages (`\endhead`), adds a "continued on next page" foot at each page break (`\endfoot`), and an empty `\endlastfoot` so the table's closing `\bottomrule` stands alone on the final page. This is a typographic apparatus change only: no table row, claim, or hypothesis is altered. It follows the longtable continuation pattern already used in the other restoration captures (for example handbook/restoration/inherited-01592-01631.tex).
