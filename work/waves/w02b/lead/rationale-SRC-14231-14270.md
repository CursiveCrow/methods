## SRC-14231-14270

The "Failure analysis" longtable in section sec:formal-practice-05 had only a single repeated head with no caption, no first-page/continuation distinction and no continuation foot, so a page break inside the table gave no sign that it continued. The corrected table carries the caption "Failure analysis" on its first head, a repeated head captioned "Failure analysis (continued)" (with no extra list-of-tables entry), a "continued on next page" foot at every page break, and an empty last foot so the closing rule stays on the final page. The head rows are repeated verbatim and no table content changed. The justification is the handbook's longtable presentation convention, which says every multi-page table carries a caption, a continuation head and a continuation foot. The apparatus matches the form already used in other restoration captures (for example handbook/restoration/inherited-01592-01631.tex).
